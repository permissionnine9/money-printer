## 第一步：确定本剧视觉风格
按以下优先级确定风格，并在本次生成的所有实体上保持统一：
1. 用户在「用户指定的视觉风格要求」中明确指定了风格 → 严格遵循，不要替换成你自己的偏好
2. 用户未指定（或只有模糊倾向）→ 由你根据剧本的题材与气质自行判断，例如：
   - 现实题材 / 生活流 / 悬疑 / 治愈系 → 真实写实照片感
   - 青春热血 / 奇幻冒险 / 校园动画 → 2D 动漫
   - 合家欢 / 科幻 / 拟人化 → 3D 渲染
   - 搞笑 / 鬼畜 / 拼贴混剪 → 对应的风格化处理
   判断依据是剧本本身，而不是任何默认偏好。

## 第二步：按实体类型与第一步的风格语法写 prompt（中文，一段式自然语言）

素材图类型由实体类型决定：
- 人物（character）→ 三视图设定素材图：这是角色的设定图/模特图（角色三视图设定），不是剧情照
- 场景（scene）→ 场景全景素材图：呈现完整空间的标准视图

人物实体要求（三视图设定素材图）：
- 同一角色的三个视角并排在同一画面：正面视角、侧面视角、背面视角，全部为全身像
- 三个视角严格一致：同一套服装、发型、体貌，自然站姿（中性站立姿势或 A 字站姿），不要戏剧化动作
- 带身高标注与比例尺：画面侧边有带刻度的身高标尺，并标注该角色的具体身高（如 175cm）——身高从角色设定合理推断（拿不准时：成年男性 170-185cm、成年女性 155-172cm、儿童按年龄递减），必须把数字写进 prompt
- 以主体特征开头：外貌/服装/体态
- 写死固定特征：核心服装与发型不要漂移
- 干净的中性背景：画面中只有这一个角色（的三个视角），无其他人物、无场景道具
- 130-220 个中文字，一段式（不要列表）

场景实体要求（场景全景素材图）：
- 以空间/光线/氛围开头
- 写死固定特征：场景的标志性元素必须出现
- 全景定场镜头构图，画面无人物
- 130-220 个中文字，一段式（不要列表）

风格语法（两类素材图通用，按第一步确定的风格选用对应的一套）：
- 真实写实：像描述一张真实存在的照片那样写（如「一张纪实的照片，……」），用真实摄影语言锚定质感——具体媒介与现场光（35mm 胶片拍摄、自然现场光、日光灯管照明）、自然肤色与生活痕迹（穿旧起皱的衣物、真实空间纵深）；禁用 cinematic lighting / hyperrealistic / ultra detailed / 8k / masterpiece 等 AI 味画质词
- 2D 动漫 / 漫画：用作画语言描述（如动漫角色立绘、赛璐璐上色、干净线稿），明确线条、上色方式、整体色调与制作气质
- 3D 渲染：用渲染语言描述（如风格化 3D 角色、次表面散射、柔和全局光照），明确材质、光照与渲染质感
- 其他风格（水彩 / 像素 / 版画 / 鬼畜拼贴等）：使用该媒介的专业术语准确描述，确保模型能够识别

  ...
