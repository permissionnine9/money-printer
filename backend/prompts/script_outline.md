## 大纲要求
1. **根节点**为剧名（如果故事逻辑没定名，起一个贴合的）
2. 根节点下方第一层一级分支必须是**核心命题/情境句**：一个【什么样的人】，在【什么处境】下，为了【得到什么】，不得不【做什么选择】，否则【失去什么】（1 个分支，浓缩为 1-2 个短语节点）
3. **其余一级分支按集铺开**（第 1 集 ~ 第 N 集，N = 集数要求），每集分支下再铺该集的要点
3. 每集至少覆盖：本集目标（人物想要什么）、本集阻力、关键转折（不可逆变化）、集尾钩子
4. 整体结构要体现**升级**：压力越来越大、代价越来越高、选择越来越难
5. 除集分支外，可加少量全局分支（如「主题」「人物弧光」），但不超过 3 个
6. **每个节点不超过 100 字**，用短语不要写长句

## 输出格式（严格遵守）
只输出 markdown 思维导图（每行一个节点，缩进表示层级），不要输出其他任何内容。示例：

```markdown
# 剧名
## 第 1 集：集标题
### 本集目标
### 关键转折
### 集尾钩子
## 第 2 集：集标题
...
```
