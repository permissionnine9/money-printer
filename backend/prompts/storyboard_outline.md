## 要求

- 必读本集分集设计文件（梗概/矛盾链/因果链/结尾摘要/节点进展），分镜切分必须忠于本集设计
- 人物外观、场景氛围严格遵循 03-entities/ 下的实体卡设定（本集 frontmatter 的 character_ids/scene_ids 指向它们），不得虚构与剧情因果冲突的内容
- 按 max_segment_duration={{max_segment_duration}} 秒的节奏将本集切分为若干分镜（不过度分片，每个分镜内容密度高）
- **本集是拍给观众看的短剧，不是剧情备忘录——分镜是按戏剧节奏导出来的，不是按事件顺序切出来的**：
  - **开场即钩子**：本集前 1-2 个分镜必须抓人——冲突先行（直接进对抗）、悬念先行（先抛问题）、或强视觉奇观；不允许从静态环境慢铺垫开场。第 1 集还须先落实大纲的叙事策略与开场设计（如有）：冷开场分镜 + 背景铺垫分镜（序幕闪回/旁白画面/字幕卡）+ 叙事视角的确立；本集含倒叙/插叙/闪回段时（见大纲「叙事策略」分支，如有），分镜要显式标出时序与触发衔接
  - **幕按起承转合组织**：`## 幕/段` 不是事件顺序的机械分段——起（钩子+开局局面）→ 承（推进累积）→ 转（本集最重的高潮/反转，给足时长与分镜密度）→ 合（情绪落点+集尾钩子留悬念）
  - **每个分镜写「戏」不写「事」**：outline 里要有动作、有情绪变化、有悬念——观众看完这段在等什么、下一段交付什么。只描述「发生了什么」的流水账分镜不合格
  - **视觉锚点是本集视觉投资重点**：大纲/分集设计中本集的视觉锚点（观众记住的画面，如有）对应的分镜给足时长与画面密度——它是观众记住这一集的画面
  - **开场认知唤起**：本集开场若依赖前情，用 1 个快速唤起手段（闪回一瞬/旁白一句/字幕一行）把观众拉回上下文，不许裸切
  - **节奏张弛**：高潮/转折分镜时长给足、切分细密；过渡交代性内容压缩合并。全片分镜时长均匀 = 没有节奏
- mindmap 是 markdown 层级导图：`# 本集标题` → `## 幕/段` → `### 分镜标题`，层级不超过 3 层
- segments 与导图中的分镜一一对应：title=分镜标题，outline=该分镜的画面/动作/剧情概述（80-150 字，具体可拍，包含人物动作与环境细节，并体现该分镜的戏剧任务）
- **有人物开口的分镜，outline 必须带台词原文**（引号内 1-2 句）——台词是短剧的灵魂：钩子段的质问、冲突段的对抗、高潮段的金句都靠台词立住；视频模型会按提示词生成对白音频。无人出声的分镜（空镜/纯动作）不硬塞
- duration=该分镜的建议时长（5~{{max_segment_duration}} 秒的整数）：根据分镜内容密度与节奏分析——动作复杂/信息量大/情绪重场给较长，过渡/空镜给较短
- overlap=与上一分镜的重叠秒数（0-3 整数，0=不重叠）：剧情/画面需连续衔接的分镜给 1-3，独立场景切换给 0；首个分镜固定为 0
