# ① 场景扩写

**输入**：用户几句话 + 要求
**输出**：有起承转合的场景序列

这一步最容易被做坏的方式是**补情节**——用户说"一个女孩在雨里等车"，你写成"一个女孩在雨里等车，结果遇到了前男友，两人回忆起过去"。这是发明，不是扩写。

**扩写补的是画面和结构，不是故事。**

---

## 第一步：锁定不变量

动手前先把用户给的拆成三类，写下来（这一步不用给用户看，但必须做）：

| 类型 | 内容 | 处理 |
|---|---|---|
| **不可动** | 人物、事件、台词、结局、品牌信息、产品卖点 | 一个字不能改 |
| **可展开** | 外观、场景细节、光线、动作过程、环境声 | 这正是你要补的 |
| **待确认** | 用户没说、但会影响整体结构的 | 只有这类才值得问 |

**判断展开 vs 发明的唯一标准：新增的东西是否改变了剧情因果。**

- 补"雨是斜的、打在伞面上溅成雾" → 展开（不改变因果）
- 补"她的伞突然被风吹翻" → 发明（造成新事件）
- 补"她穿的是一件洗旧的风衣" → 展开
- 补"风衣口袋里有一封没寄出的信" → 发明（引入新物件和新含义）

边界地带（比如"风衣口袋里有一封信"）怎么判？**问自己：删掉它，用户原本的故事还成立吗？** 成立 → 是发明，要问一句；不成立 → 是必需的补充，照做。

---

## 第二步：找戏剧支点

用户那几句话里，**最强的那一下**在哪？

三句话通常包含：一个情境 + 一个动作 + 一个结果，其中的"动作"往往就是支点。

- "地铁里，一个男人突然开始跳舞，周围人都在看手机" → 支点是**跳舞**和**无视**的对比
- "咖啡洒了，她没擦，只是看着它流" → 支点是**不擦**

支点决定整片的镜头重心：它应该拿到最多的镜头数量、最贵的运镜、最精细的特效和音效。**支点镜头平庸 = 整片平庸。** 其余镜头的作用是把它推上去。

如果用户给的内容里**找不到支点**（比如只是"展示一下我们的新产品"），那就人为造一个**视觉支点**——产品最独特的那一下（开盖、转动的 Logo、材质反光扫过），把它当作戏剧支点来对待。

---

## 第三步：拆节拍

### 单场景（8–15 秒）

按**起 → 承 → 转 → 合**四拍切：

| 拍 | 作用 | 时长占比 | 画面任务 |
|---|---|---|---|
| 起 | 建立空间与人物 | 25% | 让观众知道"这是哪、谁在这" |
| 承 | 推进动作 | 30% | 动作开始，观众预期形成 |
| 转 | 支点 / 意外 | 25% | 预期被打破或强化，**最贵的一拍** |
| 合 | 落点 | 20% | 状态定格，余味 |

**"合"不等于"结束动作"，是"情绪落点"。** 关门之后手停在门把上的一秒，就是合。

### 多场景

场景之间必须是**因果链**，不是并列陈列。

- ❌ 并列："场景1 她在办公室，场景2 她在健身房，场景3 她在咖啡馆" → 这是素材库，不是片子
- ✅ 因果："办公室被否定 → 深夜健身房发泄 → 次日咖啡馆做出决定"

每个场景结束时的**状态必须和开始时不同**。如果场景 A 的结尾和开头一样，删掉它，片子不会损失什么。

### 场景之间怎么转

转场是免费的戏剧工具，别浪费：

- **动作接动作**：上一场结尾她抬手 → 下一场开头手已经放下（暗示时间流逝）
- **声音先行**：下一场的声音提前 0.5 秒进入上一场结尾
- **视觉呼应**：同样的构图、同样的颜色，在不同场景重现

---

## 第四步：给每个场景分配戏剧任务

**一个场景只干一件事。** 有两个任务就拆成两个场景。

### 场景卡格式

**注意每一拍有八个槽位，不是一行。** 这是硬性结构——每个槽位都必须填满，空着就是没写完。

```
【场景 S1】<地点> · <时间/天气> · <时长>

  戏剧任务：<这个场景唯一要完成的事，一句话>

  ── 人物设定（全片身份锚点，必须写全）──
    主角：<年龄 + 脸型 + 发型 + 发饰 + 上衣材质与颜色 + 下装 + 鞋 + 随身物件>
           ↑ 随身物件若为用户没给的，属于"贯穿性道具"——列入交付时的「新增元素清单」
    配角：<同上，每个出场人物都要有>
    关键道具：<外观、材质、颜色、当前状态>

  ── 环境设定 ──
    地点与规模：<在哪、多大、什么建筑形制>
    地面材质：<青砖 / 夯土 / 石板 / 木板，以及它的磨损状态>
    前景常见元素：<镜头前会虚化的东西>
    中景：<主体活动的那一层有什么>
    远景：<天际线是什么、有什么建筑或自然物>
    空气中有什么：<尘 / 雾 / 水汽 / 烟 / 什么都没有>

  ── 空间方位表（全片的几何基准，必建）──
    人物与道具方位：<每个人物、关键道具在画面左/右 + 前后关系 + 大致距离>
    各人物面朝：<每个人物此刻面朝哪里（也是朝向链的起点）>
    之后每一拍的视线、转头、走动、机位都必须与这张表对得上

  ── 环境动态（世界不是只为主角转的）──
    风向与风力：<从哪吹向哪、几级；注意与光源方向分开表述>
    受风对象清单：<≥3 处会被风吹动的可见物，如布幌/鬓发/裙摆/落叶/白气>
    环境生命层：<≥1 个与剧情无关的自主动态元素（鸟/落叶/远处行人/檐角滴水），
                写明出现在哪个节拍>

  ── 光线设定 ──
    光源与方向：<光从哪来，几点钟方向，多少度>
    性质与光比：<硬光 / 软光，明暗差异大不大>
    色温与冷暖对比：<主色调 + 对比色>

  ── 起承转合（每一拍七个槽位全填，运镜排第一）──

    起 <起止时间>
      运镜叙事：<镜头怎么动 + 这个动在讲什么 + 删掉它剧情会断在哪>
      景别预案：<本拍建议景别；是特写/大特写则注明放大什么（情绪/因果/质感）>
               ↑ 特写配额从这一步开始计数，不是到第③步才想起
      主体与动作：<外观要点 + 动作三段分解：起始→过程→结束>
      空间朝向：<本拍人物位置与面朝方向、视线落点方位（与空间方位表对齐）；
               与上一拍朝向如何衔接——凭空换向是物理错误，转身必须被拍出来>
      环境三层：<前景 / 中景 / 远景各是什么具体物件>
      光线落点：<光在主体身上具体形成什么>
      材质与空气：<表面质感 + 空气中的微粒>
      声音：<这一拍里有哪些声音在响>

    承 <起止时间>
      （同上八个槽位）

    转 <起止时间>   ← 支点。全片最贵的一拍，字数也应当最多；景别预案必须给特写/中近景
      （同上八个槽位）

    合 <起止时间>
      （同上八个槽位）

  场景结束时的状态：<和开始时有什么不同>
```

**每拍正文 ≥ 80 字。** 达不到说明你在敷衍，回去把六维补满。

**"戏剧任务"写不出来，说明这个场景不该存在。**

### 运镜排第一，因为它决定这一拍能不能成立

**节拍的切换由镜头完成，不是由主体完成。**

传统写法是"角色做了什么 → 所以进入下一拍"，主体动作在驱动。要改成"**镜头做了什么 → 把什么带进了画面 → 所以剧情推进了**"。

写"运镜叙事"槽位时，强制回答三件事：

1. **镜头怎么动**（类型 + 幅度 + 速度 + 落点）
2. **这个动在讲什么**（领动制造预期 / 揭示带出转折 / 牵引建立因果 / 压迫释放情绪 / 同步反向给力量关系）
3. **删掉它，剧情会断在哪**（答不出来 → 这个运镜是装饰，重写）

举例，同一个"她发现糖葫芦"：

| ❌ 运镜缺位 | ✅ 运镜牵引剧情 |
|---|---|
| 她转头，看到糖葫芦，镜头拍她 | 【揭示】镜头越过她的肩缓慢摇过去，草靶一寸寸进入画面，最后停住——**"诱惑"是随着镜头推进被一点点交出来的**；她的脸在镜头停住后才转过来 |

**注意后者的因果方向**：不是"她看到 → 所以镜头拍"，而是"**镜头把糖葫芦交出来 → 所以她看到**"。剧情是被镜头牵引出来的。

### 展开的深度：一个对照

同一个"她跑过去"，三个深度：

| 深度 | 写法 |
|---|---|
| ❌ 概述 | 她跑向糖葫芦摊 |
| ⚠️ 及格 | 她提着裙摆跑过去，辫子甩在身后，鞋底敲在青砖上 |
| ✅ 够密度 | 她的左脚先蹬地，月白马面裙的裙摆猛地鼓起一道弧；两条短辫甩到身后又荡回来，红头绳在半空划出小圈；虎头棉鞋的鞋底一下一下砸在青砖上，发出急促的碎响；上身微微前倾，像要摔倒又稳住了；她绕过一担挑子，肩膀擦过摊主的手肘 |

**区别在于：把"跑"这个动作拆成了身体的各个部位在时间上的先后。** 这就是"动作分解"这一维的写法——**不要写"她做了什么"，写"她的身体是怎么完成这件事的"**。

## 自检

交付场景序列前过一遍：

- [ ] 用户给的不可动信息一字未改
- [ ] 所有新增内容都通过了"是否改变剧情因果"的检验
- [ ] 每个场景的戏剧任务能一句话说清
- [ ] 每个场景结束时状态有变化
- [ ] 多场景之间是因果链，不是并列
- [ ] 支点明确了，且被分配了最重的资源
- [ ] 待确认项已列出（而不是自己猜了）
- [ ] **人物设定表写全了**（外观、发饰、服饰材质颜色、随身物件）——这是后面所有镜头的身份锚点
- [ ] **环境设定写全了**（地面材质、前中后景、空气介质）
- [ ] **光线设定写全了**（方向、硬软、光比、冷暖）
- [ ] **每一拍的八个槽位都填满**，没有空槽
- [ ] **空间方位表已建**：人物/道具方位 + 各人物面朝，后续视线与调度有几何基准
- [ ] **风有风向、风力，受风对象 ≥3 处**；没有"只有一个物件在动"的孤立动画
- [ ] **环境生命层 ≥1 个**与剧情无关的动态元素，且过拍摄测试
- [ ] **人物朝向链从场景卡就锚定**：谁面朝谁，互动动作在几何上允许发生
- [ ] **每拍标注了景别预案；全场景特写+大特写预案占比 ≥ 40%**——配额从第①步开始计数
- [ ] **每拍时长 > 2.0s 的，运镜叙事里写明了拍内的运镜变化点**（预标节拍，相邻节拍间隔 ≤ 2.0s）——2 秒规则从第①步开始兜底
- [ ] **贯穿性道具、人物新增反应已列入「新增元素清单」**，交付时单列请用户否决
- [ ] 每拍正文 ≥ 80 字，转（支点）那拍字数最多

把场景序列给用户看，**明确问他"结构对不对"**——这一步定错，后面三步全部返工。确认了再进第 ② 步。
