# ① 场景扩写

**输入**：用户几句话 + 要求
**输出**：有起承转合的场景序列（场景卡）

扩写最容易做坏的方式是**补情节**。扩写补的是画面和结构，不是故事。

## 锁定不变量

| 类型 | 内容 | 处理 |
|---|---|---|
| 不可动 | 人物、事件、台词、结局、品牌信息 | 一个字不能改 |
| 可展开 | 外观、场景细节、光线、动作过程、环境声 | 这正是要补的 |

判断**展开 vs 发明**的唯一标准：**新增内容是否改变剧情因果**。补"她穿洗旧的风衣"是展开；补"风衣口袋里有一封没寄出的信"是发明（引入新物件和新含义）。

## 找戏剧支点

用户那几句话里**最强的那一下**（通常就是那个"动作"，如"咖啡洒了她没擦"里的**不擦**）。支点拿到最多的镜头数量、最重的运镜和特效——支点镜头平庸 = 整片平庸，其余镜头的作用是把它推上去。内容里找不到支点，就人为造一个**视觉支点**（产品最独特的那一下），当戏剧支点对待。

## 拆节拍

单场景（8–15s）按**起承转合**切：

| 拍 | 作用 | 时长占比 |
|---|---|---|
| 起 | 建立空间与人物 | 25% |
| 承 | 推进动作，观众预期形成 | 30% |
| 转 | 支点/意外，**最贵的一拍** | 25% |
| 合 | 情绪落点（不是动作结束——手停在门把上那一秒就是合） | 20% |

多场景必须是**因果链**不是并列陈列（❌ 办公室/健身房/咖啡馆各拍一遍 = 素材库；✅ 被否定 → 深夜发泄 → 次日做出决定）。每个场景结束时的状态必须和开始不同，否则删掉。场景间转场是免费的戏剧工具：动作接动作、声音先行 0.5s、视觉呼应。

## 场景卡格式

```
【场景 S1】<地点> · <时间/天气> · <时长>

  戏剧任务：<这个场景唯一要完成的事，一句话。写不出来 = 这个场景不该存在>

  ── 人物设定（全片身份锚点，必须写全）──
    主角：<年龄 + 脸型 + 发型 + 发饰 + 上衣材质与颜色 + 下装 + 鞋 + 随身物件>
    配角：<同上，每个出场人物都要有>
    关键道具：<外观、材质、颜色、当前状态>

  ── 环境设定 ──
    地点与规模 / 地面材质 / 前景常见元素 / 中景 / 远景 / 空气中有什么

  ── 空间方位表（全片几何基准，必建）──
    人物与道具方位：<每个人物、关键道具在画面左/右 + 前后关系>
    各人物面朝：<面朝哪里——这也是朝向链的起点>

  ── 环境动态 ──
    风向与风力（与光源方向分开表述）/ 受风对象清单（≥3 处）
    环境生命层：<≥1 个与剧情无关的自主动态元素，写明在哪一拍>

  ── 光线设定 ──
    光源与方向 / 性质与光比 / 色温与冷暖对比

  ── 起承转合（每拍填满以下槽位，运镜排第一）──
    起 <起止时间>
      运镜叙事：<镜头怎么动 + 在讲什么 + 删掉它剧情断在哪>
      景别预案：<景别 + 叙事任务（故事逻辑/伏笔/情感）；特写注明放大什么>
      主体与动作：<外观要点 + 动作三段分解：起始→过程→结束>
      空间朝向：<位置、面朝、视线落点（与方位表对齐）；与上一拍如何衔接>
      环境三层 / 光线落点 / 材质与空气 / 声音
    承 / 转 / 合：（同上；**转是支点，字数最多，景别必须是主动的重音决策**）

  场景结束时的状态：<和开始有什么不同>
```

**每拍正文 ≥ 80 字。** 节拍的切换由镜头完成，不是由主体完成——不是"她看到 → 所以镜头拍"，是"**镜头把东西交出来 → 所以她看到**"。

## 自检

- [ ] 不可动信息一字未改；新增内容全过"是否改变剧情因果"检验
- [ ] 每个场景戏剧任务一句话说清；结束时状态有变化；多场景是因果链
- [ ] 支点明确且拿到最重资源
- [ ] 人物设定写全（身份锚点）；环境/光线/方位表/环境动态写全
- [ ] 每拍槽位填满、≥ 80 字；景别预案带叙事任务；连续特写预案 ≤ 2
- [ ] 贯穿性道具、人物新增反应已列「新增元素清单」

把场景序列给用户看，**明确问"结构对不对"**——确认了再进②。
