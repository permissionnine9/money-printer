# ③ 分镜与声音设计

**输入**：电影级脚本
**输出**：分镜表（本 skill 的最终产物）

## 节奏：镜头永远在动

**节拍 = 切镜点 ∪ 运镜变化点**。相邻节拍以 **3s 为基准**；首拍在 `0.0s`；末拍覆盖片尾。常态下任意 3 秒窗口内要么切了镜、要么运动状态变了（起幅落幅、加速、变向、跟焦转移）——真正禁止的只有**镜头静止且无变化地拖下去**。

时长跟着内容走，不跟秒表走：情绪重音、复杂运镜、空间建立可以超 3s。判断标准：**静音 2 倍速快进，还在损失信息吗？** 不损失 = 时长虚胖。一镜到底可以，只要内部有运镜变化点：

```
0.0s  dolly in 慢速起幅
2.4s  转 pan right，同时跟焦到背景
4.8s  加速 push in，幅度加大
6.4s  truck left，落幅在人物侧面
```

整片允许 1–2 处**刻意静止重音**（须注明），滥用等于没有。

## 运镜牵引剧情

五种手法（每镜标注其一）：

| 手法 | 怎么做 → 制造什么 | 例子 |
|---|---|---|
| 领动 | 镜头先于主体动 → 预期 | 她还没起跑，镜头先朝草靶方向移出半尺 |
| 揭示 | 把新信息带进画面 → 转折 | 镜头越过她的肩摇过去，草靶一寸寸进入画面，最后停住 |
| 牵引 | 连接两个对象 → 因果 | 从她攥着糖的手摇到草靶上的糖葫芦，"想要"就成立了 |
| 压迫/释放 | 推近攒压力、甩开释放 → 情绪节奏 | 她盯着草靶，镜头缓推近她的脸；起跑瞬间猛地甩开 |
| 同步/反向 | 同向或反向 → 力量关系 | 她跑镜头跟着冲；或她跑镜头后退，怎么也追不上 |

判据：**删掉运镜，剧情还成立 → 装饰，重写。** 镜头领先不尾随：

| ❌ 尾随（记录仪） | ✅ 领动（叙事者） |
|---|---|
| 她转头看糖葫芦，镜头跟着摇过去 | 镜头先摇向草靶，她的脸随后转过来 |
| 她跑起来，镜头跟着她跑 | 镜头先朝草靶方向冲出去，她的身体随后冲进画面追上来 |
| 她伸手去够，镜头拍她的手 | 镜头先推到她够不到的那一寸空处，她的手随后伸进画面 |

写法：**类型 + 幅度 + 速度 + 落点**四要素，如 `truck left + pan right，中幅，慢速，落幅停在人物右后 45°`。别只用推拉摇移跟——俯瞰、螺旋拉近、crash in、whip pan、希区柯克变焦（dolly out + zoom in）、贴地横移、透过遮挡物拍……按叙事功能选。同一镜头内不塞冲突运镜；复杂运动拆成节拍逐段变化。

## 景别服从叙事

**没有配额。景别由这一拍的叙事任务决定**——故事逻辑（空间/因果/推进）全景建立、中景推进；伏笔铺垫用低调短特写、回收与铺垫呼应；情感中近景累积、特写落重音；人物处境（渺小/孤立）和空间性揭示（孤身一人/大军压境）用全景——空间对比比怼脸有力。三条硬纪律：

1. **连续特写 ≤ 2**——之后必须回中景/全景锚定空间（人物在哪、与目标什么方位），否则观众丢失空间坐标，剧情断裂
2. **每个特写答得出"放大什么"**（情绪/因果/伏笔/质感），答不出 = 凑数，删
3. **支点/情绪点/揭示点用景别跳跃强调**——跳到特写或猛拉开到全景都行，唯独不能与前后镜头同景别平着过

景别节奏：不连续三镜同景别；跳景别出剪辑感，渐进景别出推进感。人物身份重要时优先中近景/特写（人脸占比越小越难保持一致）。机位角度按表达选：仰拍强大、俯拍弱小、斜角不安。

## 视线几何与朝向链

- 视线方向必须指向目标在方位表里的真实方位；含"看/瞥/盯/回头"的镜头写明视线落点方位
- **主体背对目标禁止单镜演"看到了"**，用两连：

  ```
  镜头 A（过肩摇·揭示）：镜头先摇向草靶，草靶进入画面停住
  镜头 B（脸部特写·反应）：切她侧脸——脸转向画面右、眼睛睁大、瞳孔点亮
  镜头 C（插入镜·想象）：她的主观画面——草靶糖葫芦大特写，糖壳反光
  ```

  "看见 → 被击中 → 想要"的因果全部交给镜头
- **朝向链不断**：切镜不许凭空换向，转身必须被拍出来；双人互动前核对几何允许

## 音效四层

1. **对白**：谁说的、原话；台词长度与镜头时长对齐（时长不够时保台词完整、上调时长建议，不删台词）；按发声顺序编号 (S1)(S2)。**上游（分镜大纲/分集设计）给的台词原文必须一字不改地落进最终提示词正文**——视频模型按提示词生成对白音频，这是台词进成片的唯一通道。**画外旁白/说书人**属对白层：写明 `画外音：<内容>` 并标注压在什么画面上；字幕卡等画面可见文字逐字写出
2. **物理音效**：卡在动作和时间点——`[2.4s] 鞋跟踩碎薄冰的脆响`；写次数不写"反复"
3. **环境声**：每场景必有，带空间信息（远近、混响）——空旷仓库 = 低频嗡鸣 + 脚步回声；拥挤街道 = 远处车流 + 听不清词句的人声；雨中 = 雨打铁皮/树叶/水面的分层声
4. **非叙事音乐**：写乐器、节奏、结构（"低频弦乐持续音 + 每 4 秒一次定音鼓"，不是"紧张的弦乐"）；没有写 `N/A`

## 分镜表格式（双层，缺一不可）

索引表只做速查，**细节全在逐镜详述块里**（详述块格式见 SKILL.md 输出契约）：

```
【场景 S1】雨夜天台 · 0.0–8.0s
  戏剧任务：她决定打这通电话
  ─────────────────────────────────────
  #  时间        时长  景别/机位   运镜【叙事】        特效           声音
  1  0.0–1.6s   1.6s  中景/平视   dolly in 慢【揭示】  雨丝+镜头水渍  雨声/按键咔哒
  2  1.6–2.4s   0.8s  特写/俯拍   rack focus【牵引】  浅景深光斑     呼吸声
  ...

  环境声：持续雨声，远处车流    音乐：N/A
```

索引表里特效和声音只写关键词，详述块必须写成**行为描述**（"雨丝" → "雨滴附着在镜头前缓慢下滑，拖出透明水痕"）。

## 交付时表后附上

1. **总时长**——是否在模型单次生成区间内，超过要提示分段
2. **是否分段**——分段方案明确
3. **参考素材清单**——每个只负责一件明确的事，写清它不负责什么
4. 一条跟随分镜表的硬约束：**转成任何模型提示词后，运镜必须仍在牵引剧情**，不能压扁成"镜头跟着她跑"的记录式描述
