# ③ 分镜与声音设计

**输入**：电影级脚本
**输出**：分镜表（本 skill 的最终产物）

分镜表决定**观众看到什么、以什么节奏看到、听到什么**。

---

## 一、镜头永远在动

### 节拍定义

**节拍 = 切镜点 ∪ 运镜变化点**。

- **切镜点**：新建一个镜头
- **运镜变化点**：镜头没切，但运动状态变了（起幅→落幅、加速、变向、变焦、跟焦转移）

### 硬规则

1. 相邻节拍间隔 **≤ 2.0 秒**
2. 首个节拍在 `0.0s`——开场就在动
3. 末尾节拍覆盖片尾

任意 2 秒窗口内，**要么切了镜，要么镜头运动状态变了**。

> 是"或者"，不是"必须切镜"。机械每 2 秒切一次是 MV 碎剪，不是电影。该切时切，不该切时让镜头动起来。

### 怎么满足 2 秒规则

一镜到底的 8 秒镜头完全可以，只要它内部有 ≥4 个运镜变化点：

```
0.0s  dolly in 慢速起幅
1.8s  转为 pan right，同时跟焦到背景
3.6s  加速 push in，幅度加大
5.4s  truck left，落幅在人物侧面
7.2s  减速，焦点前移落到手中物件
```

**这就叫"镜头永远在动"** —— 没有切镜，但每一刻画面都在变化。

### 唯一例外

整片允许 **1–2 处**刻意静止作为重音（情绪落点、决定性瞬间），单次 ≤2s，必须在分镜表里注明 `【刻意静态重音】`。

滥用这个例外等于没有例外。如果一段素材里出现三处以上"刻意静止"，你在偷懒。

## 二、运镜：先牵引剧情，再谈词汇

### 运镜必须承担叙事功能

**判据：删掉这个运镜，剧情还成立吗？** 成立 → 它是装饰，重写。

五种牵引手法：

| 手法 | 怎么做 | 制造什么 | 例子 |
|---|---|---|---|
| **领动** | 镜头先于主体动起来 | **预期**——观众先于角色知道要发生什么 | 她还没起跑，镜头先朝草靶方向移出半尺 |
| **揭示** | 镜头移动把新信息带进画面 | **转折**——信息"进入画面"本身就是转折 | 镜头越过她的肩摇过去，草靶一寸寸进入画面，最后停住 |
| **牵引** | 镜头把两个物体 / 人物连起来 | **因果**——关系由镜头建立 | 镜头从左手的芝麻酥糖摇到草靶上的糖葫芦，"想要"就成立了 |
| **压迫 / 释放** | 推近累积压力，甩开释放 | **情绪节奏** | 她盯着草靶，镜头缓慢推近她的脸；她起跑瞬间镜头猛地甩开 |
| **同步 / 反向** | 同向＝陪伴加速，反向＝阻力 | **力量关系** | 她跑，镜头跟着一起冲；或她跑，镜头反而后退，怎么也追不上 |

### 铁则：镜头领先，不要尾随

| ❌ 尾随（记录仪） | ✅ 领动（叙事者） |
|---|---|
| 她转头看向糖葫芦，镜头跟着摇过去 | 镜头先摇向草靶，她的脸随后转过来 |
| 她跑起来，镜头跟着她跑 | 镜头先朝草靶方向冲出去，她的身体随后冲进画面追上来 |
| 她伸手去够，镜头拍她的手 | 镜头先推到她够不到的那一寸空处，她的手随后伸进画面、停在镜头前 |

**注意因果方向**：不是"她看到了 → 所以镜头拍"，而是"**镜头把东西交出来 → 所以她看到**"。剧情是被镜头牵引出来的。

### 动作必须明确：词汇库 + 分解

模型不会猜动作——写"她过去"它只能自由发挥。**每个动作都先给明确词汇，再做三段分解（起始→过程→结束），写清哪个部位先动、速度、力度。** 按速度档位选词参考：

**静止 / 微动**
| 词汇 | 用法 |
|---|---|
| 伫立 / 静立 | 人静立 + 风吹衣袂微动 |
| 凝视 / 眺望 | 视线锁定，身体不动，仅头部微转 |
| 屏息 | 全身静止 + 胸口起伏 |

**慢速移动**
| 词汇 | 用法 |
|---|---|
| 踱步 / 漫步 | 缓慢悠闲，手背后，一步一顿 |
| 蹑手蹑脚 | 踮脚尖 + 轻落步，无声音 |
| 缓步逼近 | 一步一顿、有压迫感的靠近 |

**中速移动**
| 词汇 | 用法 |
|---|---|
| 快步 / 疾走 | 步频快但不跑，裙摆摆动 |
| 小跑 | 轻快、碎步、身体微前倾 |

**快速移动**
| 词汇 | 用法 |
|---|---|
| 奔跑 / 疾跑 | 双臂摆动、辫子甩身后、裙摆鼓起、大步跨出 |
| 冲刺 / 疾冲 | 上身大幅前倾、步幅最大化、风声压过环境声 |
| 疾飞 / 飞梭 / 飞掠  | 快速掠过画面（人或物），带运动模糊 |
| 跳跃 / 纵身 | 蹬地腾空，滞空，落地屈膝缓冲 |
| 扑 / 扑向 | 重心前移扑出去，双手前伸 |

**打斗 / 武术**
| 词汇 | 用法 |
|---|---|
| 闪避 / 侧身 | 上身侧倾 / 后仰躲开来物 |
| 格挡 / 招架 | 小臂抬起挡格，被击退半步 |
| 挥击 / 刺出 | 拧腰转胯带动手臂挥出 / 刺出 |
| 旋身 | 以一脚为轴旋转 360°，裙摆展开 |
| 翻滚 / 倒地翻滚 | 重心下压、团身翻滚后起身 |

**瞬间爆发（多帧合成或快切）**
| 词汇 | 用法 |
|---|---|
| 瞬移 / 闪现 | 残影 + 从 A 点瞬间出现在 B 点 |
| 爆发 | 全身肌肉同时发力，动作帧模糊 |

**情绪性小动作（特写承载）**
| 词汇 | 用法 |
|---|---|
| 攥紧 / 松开 | 手指收拢关节泛白 → 缓慢张开 |
| 颤抖 | 手/唇/睫毛的细微不可控震动 |
| 顿住 | 动作半途突然停住（惊觉信号） |
| 回头 / 回眸 | 肩先转 → 头随后 → 视线最后落到位 |

**铁律：动作词不许单用。** "她奔跑"不合格，必须是"左脚蹬地、裙摆猛地鼓起一道弧、两条短辫甩到身后又荡回来、虎头棉鞋砸在青砖上"——词汇定类型，分解定物理。

### 写运镜的四要素 + 第五项

四要素：**运动类型 + 幅度 + 速度 + 落点**。

> ❌ "环绕运镜"（模型接不住）
> ✅ "`truck left + pan right`，中幅，慢速，落幅停在人物右后侧 45°"

**第五项：叙事功能。** 每个运镜都要能标注它属于上面五种手法中的哪一种。标注不出来 → 这个运镜没有叙事功能，删掉重设计。

### 基础运镜

| 中文 | 英文 | 效果 |
|---|---|---|
| 推 | `push in` / `dolly in` | 强调、聚焦、情绪收紧 |
| 拉 | `pull out` / `dolly out` | 交代环境、抽离、收尾 |
| 摇 | `pan left/right` | 横向扫视，展示空间 |
| 移 | `truck left/right` | 横移，保持主体大小不变 |
| 升降 | `crane up/down`（`pedestal`） | 起伏，改变权力关系 |
| 跟 | `tracking` / `follow` | 跟随主体 |
| 环绕 | `truck + pan` 组合 | 建立立体感 |
| 变焦 | `zoom in/out` | 与 dolly 不同：不改变透视 |
| 跟焦 | `rack focus` | 焦点在前后景之间转移 |

### 扩展运镜库（按叙事功能分类选用）

不要只会"推拉摇移跟"。下面这些每个都带明确叙事功能，**按要制造的效果选，不是按好看选**：

| 中文 | 英文 / 写法 | 叙事功能 |
|---|---|---|
| 俯视大远景 | `crane up 至高点俯瞰` | 建场、空间霸权、人物渺小（开场建空间首选） |
| 螺旋拉近 | `orbit + push in`（环绕同时螺旋收近） | 聚焦执念——视线收拢，"全世界只剩这一件东西" |
| 环绕运镜 | `orbit` / `arc around subject`（明确顺/逆时针 + 半圆/整圆） | 展示主体立体全貌，定格仪式感 |
| 急速推镜 | `crash in` / `whip zoom` | 顿悟、惊觉、恐惧突袭的瞬间冲击 |
| 甩镜转场 | `whip pan` | 快速切换到另一主体，冲击 |
| 俯冲下压 | `crane down + push in` | 压迫、逼近、力量压倒 |
| 跟随冲刺 | `tracking 低机位高速` | 动作、追逐——观众被镜头拽着跑 |
| 升空揭示 | `crane up + pull out` | 收尾升华，从主体拉到世界全景 |
| 希区柯克变焦 | `dolly out + zoom in`（反向组合） | 空间扭曲，眩晕、惊觉、认知崩塌 |
| 贴地横移 | `low angle tracking / dolly` | 紧张、隐秘、贴物潜行感 |
| 正俯顶拍 | `top-down / bird's eye` | 俯拍图案、命运感、上帝视角的冷漠 |
| 窥视透过 | `through-object`（透过窗棂/人群/门缝拍） | 偷窥感、被观察、隔了一层的关系 |
| 锁定（重音） | `locked-off` | **仅用于刻意静态重音**，全片 ≤2 处 |
| 手持呼吸 | `handheld` | 纪实、紧张、临场感 |
| 跟焦揭示 | `rack focus`（前景→背景转移） | 信息揭示——"原来还有这个" |

### 速度与幅度

速度：`极慢 / 慢 / 中 / 快 / 极快 / 瞬间（闪现、血遁等）`，或英文 `slow / moderate / fast`
幅度：`微幅（画面 10% 内）/ 中幅 / 大幅（跨越整个画面）`

### 运动的一致性

**同一个镜头里不要塞互相冲突的运镜。** "快速手持冲击变焦 + 慢速固定 + 平滑轨道"传达不出可用路径。

一个镜头 = 一条清晰的运动路径。要复杂运动，就拆成节拍，逐段变化。

## 三、景别与机位

### 特写配额：宁多勿少（优先级仅次于运镜）

| 景别 | 用途 | 占比要求 |
|---|---|---|
| **特写 / 大特写** | 情绪放大、质感、因果 | **≥ 40%** |
| **中近景** | 主体动作 + 情绪 | 凑到 ≥ 60% 的主力 |
| 中景 | 信息量、对话 | 少量 |
| 全景 / 远景 | **只做两件事**：建立空间、撑起起承转合骨架 | ≤ 30% |

**支点、情绪点、揭示点必须用特写或中近景承载。** 把情绪点给了全景，等于把最值钱的东西扔了。

每个特写都要回答"它放大了什么"——情绪（眼/唇）、因果（手的收紧与松开）、质感（材质/光）。**答不出来的特写是凑数，删掉。**

### 景别表

| 景别 | 用途 |
|---|---|
| 大远景 | 建立地点、人物渺小 |
| 远景 / 全景 | 交代人物与环境关系 |
| 中景 | 对话、动作，最常用的信息量景别 |
| 中近景 | 情绪开始可读，**人物一致性最稳的景别** |
| 特写 | 情绪、细节、道具 |
| 大特写 | 极端强调（眼睛、指尖、Logo） |

**机位角度**：平视（客观）／仰拍（强大、压迫）／俯拍（弱小、被观察）／斜角（不安）

> **身份一致性提示**：人脸在画面里占比越小越难保持一致，动作越快几何越不稳定。人物身份重要时优先用**中近景 / 特写**。

**景别的节奏**：不要连续三个镜头同一景别。跳景别（中景 → 特写 → 全景）产生剪辑感；渐进景别（中景 → 中近景 → 特写）产生推进感。

### 视线几何与朝向链（物理一致性的两条硬规则）

模型不会自己推几何——视线朝向、人物朝向必须由分镜明确给出，否则模型瞎猜，成片就是"她背对糖葫芦却在朝左看"。

**规则一：视线方向必须指向目标在空间方位表里的真实方位。** 凡含"看 / 瞥 / 盯 / 望 / 回头"的镜头，写明视线落点方位（"视线朝画面右，锁定右前方红墙根的草靶"），特写里连瞳孔高光位置都要自洽。

**规则二：主体背对目标时，禁止同镜表现"她看到了"。** 解法是"反应特写 + 想象插入"两连：

```
镜头 A（过肩摇，揭示）   镜头先摇向草靶，草靶进入画面停住      【揭示】
镜头 B（脸部特写，反应） 切她正/侧脸特写：脸转向画面右、
                        眼睛睁大、瞳孔点亮——朝向写得明明白白 【放大情绪】
镜头 C（插入镜，想象）   她的主观/想象画面：草靶糖葫芦大特写，
                        糖壳反光——"她想的就是这个"          【牵引】
```

这三连把"看见 → 被击中 → 想要"的因果全部交给镜头，不留给模型猜。

**朝向链**：人物跨镜头的面朝方向是链条，每一环要么延续上一环，要么有一拍拍出"转身"过程。切镜后凭空换向 = 物理错误。双人互动（拥抱、拽袖、递物）前，核对两人的位置与朝向在几何上允许该动作发生——不允许就先给一个调度镜头（转身、绕行）。

## 四、音效分层

声音承担一半的沉浸感。**四层分开写，一层都不能空。**

### 第 1 层：对白

- 写清谁说的、什么语言、**原话原文**
- 台词长度要跟镜头时长对齐——口型对不上，绝大多数时候是因为这句话根本说不完
- 对白按实际发声顺序编号 `(S1)`、`(S2)`，全程复用同一 ID

### 第 2 层：物理音效（绑定动作）

**关键声音必须卡在产生它的动作和时间点上。**

```
[0.8s] 拉环声，随后是短促的气泡声
[2.4s] 鞋跟踩碎薄冰的脆响
[5.1s] 打火机砂轮摩擦两次，第三次点燃
```

注意"两次""第三次"——**写次数，不写"反复"**。次数是可执行的，反复不是。

### 第 3 层：环境声（最容易漏，最能拉开差距）

**每个场景都必须有环境声层。** 环境声要有空间信息：

| 空间 | 环境声写法 |
|---|---|
| 空旷仓库 | 低频嗡鸣，混响时间长，脚步有回声 |
| 拥挤街道 | 远处车流，人声嘈杂但听不清具体词句，偶尔的喇叭 |
| 深夜室内 | 冰箱压缩机嗡鸣，钟表走时，偶尔远处车辆驶过 |
| 雨中 | 雨打在不同材质上的分层声——铁皮、树叶、水面 |
| 密闭车内 | 低频路噪，引擎声，转向灯的规律咔哒 |

**空间的"大小"主要靠混响传达。** "空旷仓库的混响"和"贴着耳朵的呼吸声"是两个完全不同的空间，环境声要传达出这个差别。

### 第 4 层：非叙事音乐

观众能听见、角色听不见的配乐。**写乐器、节奏、结构，不写情绪词。**

| ❌ 情绪词 | ✅ 可执行 |
|---|---|
| 紧张的弦乐 | 低频弦乐持续音，每 4 秒一次定音鼓 |
| 温馨的钢琴 | 单音钢琴，缓慢，音符间隔 1.5 秒以上，不加踏板 |
| 科技感电子乐 | 合成器脉冲每 0.5 秒一次，中频，无旋律 |
| 逐渐推向高潮 | 弦乐声部从 2 个增加到 6 个，音量每 8 秒抬升一次 |

**"音乐从 X 变到 Y"是可执行的，"音乐逐渐紧张"不是。**

没有配乐就明确写 `N/A`，不要留空。

## 五、分镜表格式

**双层结构：索引表 + 逐镜详述。缺一不可。**

索引表只做速查，**细节全在逐镜详述块里**。只有表格没有详述 = 没做完。

### 第一层：索引表

```
【场景 S1】雨夜天台 · 0.0–8.0s
  戏剧任务：她决定打这通电话
  光线：单一霓虹光源（青），无补光
  ─────────────────────────────────────────────
  #  时间        时长  景别/机位   运镜【叙事功能】      特效          声音
  1  0.0–1.6s   1.6s  中景/平视   dolly in 慢【揭示】   雨丝+镜头水渍  雨声/按键咔哒
  2  1.6–2.4s   0.8s  特写/俯拍   rack focus【牵引】    浅景深光斑     呼吸声
  3  2.4–4.0s   1.6s  中近景/侧   手持 微幅【压迫】     雨打湿肩头     雨声变闷
  4  4.0–5.2s   1.2s  全景/仰拍   crane up 慢【领动】   体积光穿透雨幕 环境声展开
  5  5.2–6.8s   1.6s  大特写/平   push in 极慢【压迫】  皮肤纹理       拨号音
  6  6.8–8.0s   1.2s  中景/平视   pull out 慢【释放】   焦外光斑       接通声【刻意静态重音】

  环境声：持续的雨声，远处车流，楼下偶尔的关门声
  音乐：N/A
```

### 第二层：逐镜详述（每个镜头一块）

**每个镜头都要写到这个密度。** 人物外观可复用（同一人物首次写全，之后写"外观同 S1-1"），**其余各维每镜重写**——运镜、动作、朝向、环境、光线、材质、声音每时每刻都在变。

**"运镜叙事"是详述块的灵魂，排第一。** 它要同时回答三件事：镜头怎么动、这个动在讲什么、**删掉它剧情断在哪**。第三问答不出来 → 这个运镜可以直接删掉，重新设计一个真的在讲故事的。

```
┌ 镜头 1 · 0.0–1.6s · 中景/平视 · dolly in（中幅 / 慢 / 落幅停在手部）
│ 运镜叙事：【揭示】镜头先从她身后朝电话亭推近，把"无人接听"的红灯带进
│          画面；她抬手的动作是对这个揭示的回应——删掉这个推近，
│          "她意识到没人接"这件事就不存在了
│ 人物外观：齐眉刘海，两条短辫用红头绳扎着，鬓边别一朵绒花，大红织金
│          小袄的袖口磨出一点毛边，月白马面裙下露出虎头棉鞋的鞋尖
│ 动作分解：右手从身侧抬起 → 食指伸直、其余三指收拢 → 指尖悬在按键上方
│          一寸处停住 → 按下 → 手腕回收
│ 空间朝向：她在画面左、面朝画面右的电话亭；视线落点在电话亭按键区，
│          与场景方位表一致；与上一拍朝向的衔接方式
│ 环境三层：前景是虚化的雨滴贴着镜头玻璃滑落；中景是她和铁皮电话亭；
│          远景是被雨水泡糊的霓虹招牌，红绿两色在积水里拉成竖条
│ 光线落点：单一霓虹光源（青）从画面左上斜下，在她右脸颊扫出一道冷色
│          高光，左手完全落在暗部
│ 材质空气：雨滴附着在镜头前，焦点在雨滴与她之间游移；大衣肩头的呢料
│          吸了水颜色变深，表面立起一层细密绒毛
│ 特效（主）：镜头水渍——雨滴缓慢下滑，拖出一道透明水痕，短暂扭曲后方画面
│ 声音：雨声（密集、贴耳）/ 按键咔哒（单次、干脆）/ 远处车流（低、闷）
└
```

**注意最后四行**——"特效"和"声音"在索引表里只有关键词，在详述块里必须写成**行为描述**：
"雨丝"不够，要写"雨滴附着在镜头前，缓慢下滑，拖出一道透明水痕，短暂扭曲后方画面"。

### 表下方的两个补充块

- **环境声**：贯穿整个场景的底噪，单独一行
- **音乐**：非叙事配乐，没有写 `N/A`

## 七、交付分镜表时随表附上的信息

分镜表是本 skill 的最终产物。交付时在表后附上这些信息，方便用户后续接入任何工具或模型：

1. **总时长**——是否在常见模型的单次生成区间内（如 4–15 秒），超过了就要提示用户分段
2. **是否分段**——超过单次上限或用户要求长视频时，明确分段方案
3. **有没有参考素材**——图片 / 视频 / 音频，各几个，分别负责什么
4. **一条跟随分镜表的硬约束**：无论用户后续用什么工具转换格式，运镜必须仍然在牵引剧情，不能被压扁成"镜头跟着她跑"这种记录式描述

第 3 条特别注意：**每个素材只负责一件明确的事**，并写清它**不**负责什么。素材堆多了不会提高一致性，反而产生平均脸、产品变形和风格串台。

本 skill 到此交付完成，不调用任何其他 skill。
