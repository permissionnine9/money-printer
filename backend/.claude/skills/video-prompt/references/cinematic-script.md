# ② 电影级脚本

**输入**：场景序列
**输出**：每个场景的文字脚本，细节丰富、有画面感

"电影级"不是滤镜，是三件事做对了：**光线有来源、构图上主体占满画面的三分之二、材质和空气被写出来**。

---

## 一、画面感 = 可拍摄性

### 删词测试

写完任何一句，把形容词删掉，看画面信息还在不在。

| 空词（删掉后句子空了） | 可拍的写法 |
|---|---|
| 她很孤独 | 她坐在没开灯的客厅地板上，电视待机红灯是唯一光源，在侧脸投下一小块红斑 |
| 环境很高级 | 大理石台面上放着一只没喝完的咖啡杯，杯壁凝着水珠，晨光从右侧斜切进来 |
| 他很强大 | 人物从低角度仰拍，占满画面三分之二，背景虚化成一片暖色光斑 |
| 科技感十足 | 冷白 LED 灯带沿着天花板边缘延伸，在抛光地面上投下等距的青色反光 |
| 氛围很压抑 | 天花板低垂，只有一盏吊灯，人物坐在光斑边缘，半张脸在暗部 |

**规律**：把形容词翻译成 **光源 + 主体占位 + 材质 + 空间关系**——**四件事必须全部命中，不是四选二**。

### 密度：删词测试只是及格线

过了删词测试，只说明这句话不是废话，**不代表它写够了**。真正的标准是**拍摄测试**：把这个场景交给一个没见过你的人，他能不能**原样摆出来**？

提升密度的办法不是加形容词，是**把每个元素往下钻一层**：

| 太薄 | 钻一层 | 再钻一层（够密度） |
|---|---|---|
| 她穿着古装 | 她穿着红衣 | 大红织金小袄，袖口磨出一点毛边，领口露出月白衬领 |
| 宫墙很旧 | 宫墙的红漆剥落了 | 红漆起了翘皮，露出底下灰白的灰浆，一道裂纹从墙根斜着爬到半腰 |
| 市集很热闹 | 市集上有许多摊子 | 席棚摊子上摆着绢花、兔儿爷、糖人、香囊，布幌在风里一下一下地招展 |
| 阳光很好 | 下午的阳光照进来 | 冬日斜阳从右后 30° 切入，在她左脸勾出一道暖色边缘光，照亮光柱里缓慢游移的细尘 |

**钻不下去的时候，问自己三个问题**：这个东西是什么材质？它现在什么状态？光打在它上面会怎样？

### 七维清单（每个节拍都要齐）

| 维度 | 一句话要求 |
|---|---|
| 人物外观 | 五官、发型、发饰、服饰材质与颜色、随身物件 |
| 动作分解 | 起始→过程→结束，写清哪个部位先动 |
| 空间与朝向 | 人物位置、面朝方向、视线落点的方位（与场景卡方位表对齐；朝向变化要写出转身过程） |
| 环境三层 | 前景 / 中景 / 远景各有什么具体物件 |
| 光线落点 | 来源方向 + 性质 + 在主体身上形成什么 |
| 材质与空气 | 表面质感 + 空气中的微粒 |
| 声音 | 这一拍里有哪些声音在响 |

**缺一维就是没写完。** 量化下限：单个节拍 ≥ 80 字、≥ 8 个具体实物名词；单个场景脚本 ≥ 600 字。

### 环境活性：力是系统的，生命是自主的

环境静止、单一，画面就是影棚。两个硬要求：

1. **风必须系统性存在**：风向 + 风力写清，并作用于**同场景 ≥ 3 处**可见对象（布幌、鬓发、裙摆、落叶、呼吸白气……），方向一致。只有一件东西在动 = 孤立动画，一眼假。
2. **环境生命层**：每个场景 ≥ 1 个与剧情无关的自主动态元素（天上过鸟、树叶飘落、远处行人、檐角滴水），写明出现在哪一拍，且要过拍摄测试——"两只寒鸦从画面右上斜掠过殿顶，翅膀连拍两下"，不是"有鸟飞过"。

**动必有因**：画面里每个运动的物体都要能回答"谁/什么让它动"（风/重力/触碰/动物/惯性）。答不出来的运动删掉，或给它一个因。

### 不要写观众看不见的东西

内心活动、前史、人物关系——全部转成可见物：

- "她在犹豫" → 手指在门把上停住，指节发白
- "他想起过去" → 视线落在桌上的一张旧照片，焦点从照片缓慢移到窗外
- "两人关系疏远" → 同一张餐桌，两人各看各的手机，桌上的菜没动

**道具是内心活动的外化装置。** 需要表达什么，就找一件能承载它的实物。

## 二、光线设计（电影感的最大来源）

**每个场景必须能回答：光从哪来？** 光没有来源，画面立刻变廉价。

### 光位

| 光位 | 效果 | 什么时候用 |
|---|---|---|
| 顺光 | 平、无戏剧性 | 产品展示、需要清晰交代外观 |
| 侧光（45°） | 立体、质感强 | 默认选择，人脸与材质都好看 |
| 侧逆光 / 轮廓光 | 勾边、分离主体与背景 | 人物在杂乱背景前、需要"发光"感 |
| 逆光 | 剪影、氛围 | 强情绪、身份不明、开场建立 |
| 顶光 | 眼窝阴影、压迫 | 审讯感、不适感、疲惫 |
| 底光 | 反常规、诡异 | 恐怖、反常、非自然光源（手机屏幕） |

### 光比

**光比是"高级感"的真正来源，不是滤镜。**

- 高光比（亮部与暗部差异大）→ 戏剧性、硬朗、类型片
- 低光比（差异小）→ 柔和、日常、广告片

写脚本时明确说出来："单一霓虹光源（青），无补光，人物正面在暗部"——这一句比十个"氛围感"有用。

### 色温对照

冷（青蓝 5600K+）与暖（钨丝橙 3200K）的**并置**是电影感的常用手法：

- 冷环境 + 暖人脸 → 人在冷空间里保有温度
- 暖环境 + 冷人脸 → 人在熟悉空间里格格不入

单一色温全片铺满 = 平。**至少要有冷暖对比**，哪怕是极轻微的。

## 三、构图与景深

- **主体占位**：重要时刻主体占画面 2/3；建立空间时可以让主体小、环境大
- **前中后景**：好画面有三层。前景（虚化的桌角、雨滴、栏杆）→ 中景（主体）→ 远景（环境）。
- **景深**：浅景深（大光圈）分离主体，用于特写与情绪；深景深用于交代环境关系
- **负空间**：人物看向的方向要多留空间，否则画面"堵"

**前中后景是提升画面档次最便宜的手法。** 只要在镜头前放一个虚化的前景元素（雨滴、玻璃反光、飘动的窗帘、行人的肩膀），画面立刻从"拍摄"变成"拍摄过"。

---

## 四、特效库

特效分三类，**各司其职**：真实感 / 细节感 / 高级感。这三类正好对应你要的三个提升方向。

### 特效与特写是天然搭档（优先级仅次于运镜）

**特效是微小的东西，远景里根本看不见，特写里才存在。** 这是"影视感"的第一素材来源。

- **微观材质类（B类）特效必须绑定特写镜头**——远景里写"她睫毛上有霜花"不可见，特写里才是特效
- **每个特写镜头至少 1 个特效承载点**（材质 / 空气 / 光学任选）
- 远景 / 全景只用**大气类（A类）**特效铺氛围（雾、蒸汽、体积光），不承担质感任务
- 特写 + 大特写 ≥ 全片镜头数 40%；特写 + 中近景 ≥ 60%
- 给足特效 = 让**更多镜头**带上特效，不是单镜堆量（每镜头主特效 ≤ 2，避免打架）

### A 类：大气与物理 → 真实感

让画面"有空气"。**这类特效最容易被忽略，也最能拉开差距。**

| 特效 | 写法示例 |
|---|---|
| 浮尘 | 午后斜阳从百叶窗缝隙切入，照亮空气中缓慢浮游的尘埃 |
| 雾气 | 地面薄雾贴着地面流动，被逆光切成可见的层次 |
| 雨 | 斜雨打在伞面溅成细雾，雨丝在霓虹前形成亮线 |
| 蒸汽 | 咖啡杯口升起的热气，在冷调背景里被侧光照出轮廓 |
| 体积光 | 天花板射灯形成可见光柱，随人物走动被切断 |
| 风 | 风穿过窗帘，织物缓慢鼓起再落下 |
| 镜头水渍 | 雨滴附着在镜头前，焦点在雨滴与水珠后的世界之间游移 |

**写法要点：特效必须绑定光源。** "有浮尘"不可拍，"光束里的浮尘"可拍。

### B 类：微观与材质 → 细节感

让观众"摸得到"。

| 特效 | 写法示例 |
|---|---|
| 皮肤 | 侧光下皮肤的细密纹理与绒毛，鼻尖有细微油光 |
| 发丝 | 逆光中边缘发丝透光，随头部转动飘起再落下 |
| 织物 | 针织毛衣的纤维在侧光下根根可见，随呼吸起伏 |
| 金属 | 拉丝金属表面随镜头移动，反光带缓慢扫过 |
| 液体 | 杯壁水珠缓慢下滑，汇合成一道水痕 |
| 表面瑕疵 | 旧木桌的划痕与包浆在斜射光里显出立体感 |

**要点：微观特效靠"侧光 / 逆光 + 镜头靠近"触发。** 平光下什么都看不见。

### C 类：光学与摄影机 → 高级感

让观众觉得"这是用机器拍的"，而不是"这是生成出来的"。

| 特效 | 写法示例 |
|---|---|
| 变形宽银幕眩光 | 镜头转向光源时，一道水平蓝色眩光横贯画面 |
| 镜头呼吸 | 焦点转移时，画面边缘出现极轻微的缩放呼吸 |
| 焦外光斑 | 背景灯光虚化成椭圆光斑，随镜头移动缓慢游移 |
| 快门拖影 | 手快速挥过时留下轻微的动态模糊拖尾 |
| 胶片颗粒 | 全片覆一层细密胶片颗粒，暗部尤其明显 |
| 漏光 / 光晕 | 光源在画面上缘造成轻微的暖色光晕溢出 |
| 色散 | 画面边缘高反差处出现极轻的紫边 |

### 搭配原则

1. **每镜头 1–2 个主特效**。三个以上开始互相打架，画面变脏。
2. **一个负责真实感（A类）+ 一个负责高级感（C类）** 是最稳的组合。
3. **全片保持一致的"特效签名"**：选定 1–2 个 C 类特效贯穿全片（比如全片胶片颗粒 + 变形镜头眩光），这构成片子的视觉风格。乱换 = 风格散。
4. **先写特效的行为，再写它的名字**。永远描述"光怎么走、粒子怎么动"，不要只给术语。

## 五、脚本格式

每个场景按这个结构写：

```
【场景 S1】<地点> · <时间/天气>

  运镜总纲：<这个场景的镜头怎么带着剧情走——从哪出发、经过什么、落在哪>
  光线：<来源 + 光位 + 光比 + 色温>
  构图：<主体占位 + 前中后景 + 景深>
  材质与空气：<A类 + B类特效>
  光学风格：<C类特效，全片统一>
  ────────────────────────────────────────
  文字脚本：
    <画面描述，一段话，包含人物外观、动作轨迹、环境细节>
```

**"运镜总纲"写的是这个场景的镜头怎么牵引剧情**，不是镜头清单。它回答：镜头从哪里开始、经历了什么运动、最后停在什么上——**而这三步恰好就是剧情的起承转合**。

例："镜头从市集的喧闹里贴着地面滑行出发，跟着她的脚步爬升、穿过人群，最后越过她的肩膀落在草靶上停住——**这一条运动轨迹，就是'玩耍 → 发现'的全部剧情**。"

**文字脚本里要写清**：

- 人物外观（年龄感、发型、服装材质与颜色）——**这是跨镜头身份一致性的锚点**
- 完整动作（起始状态 → 运动过程 → 结束状态）
- 环境的具体物件（不写"凌乱的房间"，写"桌上三只没洗的杯子、椅背搭着一件外套"）

## 自检

- [ ] 每句都过了删词测试
- [ ] **每个节拍都过了拍摄测试**（没见过的人能原样摆出来）
- [ ] **每个节拍七维齐全**，没有缺维
- [ ] **视线/朝向写清方位**，与场景卡空间方位表一致；朝向变化写出了转身过程
- [ ] **风作用于 ≥3 处且方向一致**；环境生命层 ≥1 个且过拍摄测试；动必有因
- [ ] **每个节拍 ≥ 80 字、≥ 8 个具体实物名词**
- [ ] **每个场景脚本 ≥ 600 字**
- [ ] 没有"四选二"式的敷衍——光源、主体占位、材质、空间关系四项全中
- [ ] 每个场景都能回答"光从哪来"
- [ ] 有冷暖对比，不是单一色温铺满
- [ ] 画面有前中后景层次
- [ ] 特效数量克制（每镜头 ≤2 主特效），且绑定光源或运动
- [ ] **微观材质类特效均绑定特写镜头**（远景里不出现质感特效）
- [ ] **每个特写镜头 ≥1 个特效承载点**
- [ ] **特写+大特写 ≥ 40%，特写+中近景 ≥ 60%**
- [ ] 全片 C 类特效签名统一
- [ ] 人物外观写清了（后续镜头要靠这个保持一致性）
- [ ] 没有写内心活动，全部转成了可见物
