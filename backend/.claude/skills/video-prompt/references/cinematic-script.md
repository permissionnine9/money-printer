# ② 电影级脚本

**输入**：场景序列
**输出**：每个场景的文字脚本，细节丰富、有画面感

## 可拍摄性 = 画面感

每句描述过**拍摄测试**：拿给没见过你的人，他能原样摆出来。方法是把形容词翻译成**光源 + 主体占位 + 材质 + 空间关系**：

- ❌ 她很孤独 → ✅ 没开灯的客厅地板上，电视待机红灯是唯一光源，在她侧脸投下一块红斑
- ❌ 宫墙很旧 → ✅ 红漆起了翘皮，露出灰白的灰浆，一道裂纹从墙根斜爬到半腰

密度不够就往深钻一层（材质是什么、什么状态、光打上去会怎样）：

| 太薄 | 钻一层 | 够密度 |
|---|---|---|
| 她穿着古装 | 她穿着红衣 | 大红织金小袄，袖口磨出毛边，领口露出月白衬领 |
| 市集很热闹 | 市集上有许多摊子 | 席棚摊子上摆着绢花、兔儿爷、糖人、香囊，布幌在风里一下一下地招展 |
| 阳光很好 | 下午的阳光照进来 | 冬日斜阳从右后 30° 切入，在她左脸勾出一道暖色边缘光，照亮光柱里游移的细尘 |

密度要求：具体名词与动作分解写足即止，**不设字数下限、不为凑字注水**（示例行的密度就是标准）。

**不写观众看不见的东西**：内心活动、前史、关系——全部转成可见物（"她在犹豫" → 手指停在门把上，指节发白）。道具是内心活动的外化装置。

## 七维清单（每拍必齐，缺一维没写完）

| 维度 | ❌ 太薄 | ✅ 够密度 |
|---|---|---|
| 人物外观 | 穿古装的小女孩 | 齐眉刘海，短辫用红头绳扎着，鬓边别一朵绒花，大红织金小袄袖口磨出毛边 |
| 动作分解 | 她跑过去 | 左脚蹬地、裙摆鼓起、辫子甩到身后又荡回来、上身前倾、连跑三步 |
| 空间与朝向 | 她看向糖葫芦 | 她在画面左三分之一、面朝画面右；糖葫芦摊在右前方红墙根，视线锁定草靶 |
| 环境三层 | 热闹的市集 | 前景虚化的糖人担子，中景是她，远景席棚布幌和更远的宫墙黄瓦 |
| 光线落点 | 光线很美 | 冬日斜阳从右后 30° 切入，左脸一道暖色边缘光，其余落在冷调阴影里 |
| 材质与空气 | 质感很好 | 织金小袄随动作泛出细密金点，光柱里浮着缓慢游移的细尘 |
| 声音 | 有环境音 | 远处铜盆撞响的脆声、摊位人声嗡鸣、鞋底敲青砖的紧凑节奏 |

## 光线与构图

每个场景能回答**"光从哪来"**——光没有来源，画面立刻变廉价。写明光位、光比（高光比戏剧、低光比柔和）、冷暖对比（单一色温铺满 = 平）。构图给前中后景三层、浅景深分离主体、视线方向留负空间。

## 特效三类

| 类别 | 负责 | 写法示例 | 纪律 |
|---|---|---|---|
| 大气/物理 | 真实感 | 地面薄雾贴地流动，被逆光切成可见的层次 | 远景铺氛围用 |
| 微观/材质 | 细节感 | 针织纤维在侧光下根根可见，随呼吸起伏 | **必须绑特写**——远景里看不见 |
| 光学/摄影机 | 高级感 | 背景灯光虚化成椭圆光斑，随镜头移动缓慢游移 | 全片统一签名 |

每镜头主特效 ≤ 2，绑定光源或运动，**写行为不写名字**。特写的数量由叙事任务决定（见 `shot-and-sound.md`），不设配额。

## 脚本格式

```
【场景 S1】<地点> · <时间/天气>

  运镜总纲：<镜头怎么带着剧情走——从哪出发、经过什么、落在哪；
           这条运动轨迹就是本场景的起承转合>
  光线 / 构图 / 材质与空气 / 光学风格：各一行
  ────────────────────────────────
  文字脚本：<画面描述，含人物外观、完整动作轨迹、环境具体物件>
```

**人物外观在这里写全**——这是跨镜头身份一致性的锚点。

## 自检

- [ ] 每句过删词测试（删掉形容词，画面信息还在），每拍过拍摄测试
- [ ] 每拍七维齐全、无注水
- [ ] 每场景答得出"光从哪来"，有冷暖对比，有前中后景
- [ ] 特效 ≤ 2/镜头、绑光源、写行为；微观特效绑特写；特写由叙事任务决定
- [ ] 没有内心活动，全部转成可见物
