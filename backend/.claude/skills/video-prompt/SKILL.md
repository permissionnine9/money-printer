# 视频提示词生成

把用户几句话的创意，变成一份**视频生成模型可直接执行的提示词（分镜表）**。流水线：**零散想法 → 场景序列 → 电影级脚本 → 分镜表**，全部由本 skill 完成，不调用其他 skill。

质量判据只有一条：**模型拿到提示词，每一秒画面都被安排得明明白白。**

## 流水线：三步走

| 步骤 | 做什么 | 读哪个文件 |
|---|---|---|
| ① 场景扩写 | 三句话 → 有起承转合的场景序列 | `references/scene-expansion.md` |
| ② 电影级脚本 | 每个场景 → 细节丰富的文字脚本 | `references/cinematic-script.md` |
| ③ 分镜设计 | 脚本 → 带运镜/特效/音效的分镜表（最终产物） | `references/shot-and-sound.md` |

不要跳步——直接从三句话跳到分镜，产出的是漂亮但空洞的镜头拼盘。**第①步做完必须停下让用户确认结构**（结构定错后面全返工）；确认后②③连续完成、一并交付。

## 两种调用模式

- **对话模式**（用户直接给创意）：走完整三步，第①步停下让用户确认结构
- **管道模式**（后端程序调用：输入已含分镜大纲、剧本上下文、参考图清单、overlap 与上一段提示词）：大纲已定，跳过①的停下确认，直接内联②的设计思考，输出③的最终产物

## 七条铁律

### 一、细节密度：每一帧都要能被摆出来

描述要过**拍摄测试**：拿给没见过你的人，他能原样把画面摆出来。"她在热闹的市集里跑"不行——哪些摊位、什么地面、小跑还是疾奔、手里有什么？

- 细节 = 具体名词 + 动作分解 + 可测量的物理量，不是形容词堆砌（"斑驳沧桑的宫墙"零信息；"红漆起了翘皮，露出灰白的灰浆，裂纹从墙根斜爬到半腰"才是细节）
- 动作写分解不写概述：写"她的身体怎么完成这件事"——哪个部位先动、幅度、速度
- 密度优先、不注水：**每个镜头块 ≤ 300 字**，写满即止——重复已知信息等于给视频模型加噪声
- **永远不写观众看不见的东西**——内心活动、前史、人物关系，全部转成动作、道具、光线。**观众听得到的内容（台词、画外旁白）除外**：它们按铁律五、六原样保留进提示词，不转成画面

### 二、运镜牵引剧情——镜头是叙事者，不是记录仪

内审判据（只用于设计，**不写进产物**）：删掉这个运镜，剧情还成立吗？成立 → 它是装饰，重写。

镜头要**领先**，不要**尾随**：❌"她转头看向糖葫芦，镜头跟着摇过去"是记录；✅"镜头先摇向草靶，她的脸随后转过来"才是叙事——"被诱惑"是被镜头牵引出来的。

每个运镜写明**类型 + 幅度 + 速度 + 落点**（写 `truck left + pan right`，不写"环绕运镜"），并标注叙事手法：**领动**（先于主体动，制造预期）/ **揭示**（把新信息带进画面，即转折）/ **牵引**（连接两个对象，建立因果）/ **压迫释放**（推近攒压力、甩开释放）/ **同步反向**（同向陪伴、反向阻力）。

### 三、景别服从叙事——不为特写而特写

**景别由这一镜的叙事任务决定，先定任务再定景别**；从景别倒推理由 = 本末倒置：

| 叙事任务 | 首选景别 |
|---|---|
| 故事逻辑：空间、位置关系、因果推进 | 全景/远景建立，中景推进 |
| 伏笔：铺垫 | 低调短特写 / 景深 rack focus（拍重了变剧透） |
| 伏笔：回收 | 回到铺垫的近似景别与构图——"认出"由镜头完成 |
| 情感：累积 / 落点 | 中近景累积，特写落重音 |
| 人物处境（渺小/孤立/被围困）、空间性揭示 | 全景/远景——空间对比比怼脸有力 |

硬约束：

- **连续特写 ≤ 2 个**，之后必须回中景/全景锚定空间——连续特写让观众丢失"人在哪、和谁"的坐标，剧情从这里断裂
- **特写是重音不是达标项**：该放大时果断给特写——首次认脸、情绪落点、伏笔、质感揭示，每个特写都答得出"放大什么"，答不出就是凑数，删；推进剧情、建立空间、交代关系用中景/全景 + 运镜牵引、空间对比、环境反衬同样讲故事——特写少而准比多而滥有力，怼脸拼盘没有电影感
- **支点/情绪点/揭示点用景别跳跃强调**——跳特写或猛拉开都行，唯独不能与前后镜头同景别平着过
- **景别要有呼吸**：场景内按"建立（全景/远景锚定空间）→ 推进（中景主力）→ 重音（特写落点）"分布；全片特写密度由故事密度决定，不设配额、不强制每镜

### 四、特效有纪律

- 特效写**行为**不写名字："午后斜阳从百叶窗缝隙切入、照亮浮尘、形成可见光柱"可拍，"丁达尔效应"不可拍
- 绑定光源或运动；每镜头主特效 ≤ 2（给足 = 更多镜头带特效，不是单镜堆量）
- 景别跟着叙事走，特效跟着景别走：微观材质类特效必须绑特写（远景里根本看不见），远景只用大气类铺氛围——不为"放微观特效"把本该全景的镜头怼成特写
- 特写与特效互为搭档：**确有重要特写时，至少给 1 个特效承载点**（材质/空气/光学任选）
- 全片保持统一的光学特效签名（如胶片颗粒 + 变形眩光）

### 五、音效分四层

对白（原话，写成 `<d>[中文] 原话。</d>`——这是模型认识的对白标记，说话人按发声顺序编 `(S1)(S2)` 并全程复用；台词长度与镜头时长对齐；**画外旁白/说书人也属这一层**——写成 `画外音 <d>[中文] 内容</d>`，并标注它压在什么画面上）/ 物理音效（**卡在动作和时间点**：`[6.2s] 拉环声`，写次数不写"反复"，留在每镜声音行）/ 环境声（每场景必有的空间底噪，带远近混响信息——最易漏的一层，落在头部「环境底噪」行）/ 非叙事音乐（写乐器、节奏、结构，不写情绪词，落在头部「音乐」行）。没有配乐写 `N/A`，不留空。**画面可见的文字（字幕卡、片名、年代地点交代）逐字写出**——开场铺垫用它立背景，比旁白更安静有力。

### 六、忠于输入 ≠ 不许展开

用户的**剧情、人物、台词、事件不能改也不能加**。判断标准：**新增内容是否改变剧情因果**——补外观、光线、动作过程是展开（正是本 skill 的工作）；加新转折、新道具含义是发明，要问。贯穿性道具、人物新增反应属于灰区：可用，但交付时单列「新增元素清单」给用户否决。

**上游给了台词（分镜大纲/分集设计里的引号内容）→ 必须原样写进最终提示词的对白层**，一字不改——视频模型按提示词生成对白音频，台词丢了这段就是默片。上游没给台词 → 不虚构。台词较长而建议时长不够时，**保台词完整并上调分镜时长建议，绝不删减台词凑时长**。

用户没给的时长/画幅/风格按默认处理并在交付时说明（单场景 8s、横屏 16:9）；**单段时长 ≤ 15s（模型单次生成上限），更长必须拆多段**。只有缺**会改变整体结构**的信息（单段还是多段、总时长量级、竖屏还是横屏）才先问。用户口头说"图1/参考视频1"时按给定顺序映射编号，回复开头用一行确认映射关系。**一次只让用户改一个变量**，他才能判断哪项修改起了作用。

### 七、空间物理一致

AI 视频最容易被识破的破绽不是不够美，是**几何不自洽**：

- 设计前先建**空间方位表**：每个人物、关键道具在画面左/右 + 前后关系，各面朝哪（表落在产物头部"空间方位"行）。此后每镜的视线、转头、走动、机位都与表对齐
- 视线方向必须指向目标的真实方位；**主体背对目标时禁止单镜硬演"看到了"**，用"反应特写 + 想象插入"两连
- **朝向链不断**：切镜后人物不许凭空换向，转身过程必须被某个镜头拍出来；双人互动前核对几何上允许发生
- **环境活性**：风作用于同场景 ≥ 3 处且方向一致（❌ 只有风车转；✅ 风车转 + 布幌同向招展 + 鬓发裙摆被吹起 + 干叶贴地滚过）；每场景 ≥ 1 个与剧情无关的生命层动态（过鸟、落叶、远处行人）；每个运动的物体答得出"谁让它动"
- 身份一致性：人脸在画面里占比越小越难保持一致——需要观众认脸的镜头（首次出场、情绪重音）优先中近景/特写；全景/远景中人物身份用**强识别外观锚点**保持（服饰色彩、轮廓剪影、随身道具——人物设定里写全的那些），不为此硬凑近景；全景环境元素具体、动线简单，避免多人复杂交互
- **稳定称呼**：同一人物全程用同一个称呼（如"阿禾"），不用"女孩/少女/她"近义词混称——换称呼等于把同一个人重新介绍成新主体

## 输出契约

产物是**给视频生成模型（MiniMax H3）的可执行指令**——模型只执行指令，不读论证。结构标记（`[Shot N] At`、`<d>`、`<Picture N>`）是模型训练时对齐的信号，格式照写；正文用中文。直接输出：

**开头四行**（场景定位 + 段级信息）：

```
【场景 S1】雨夜天台 · 全段 0.0–10.0s · 16:9 · 冷色霓虹夜景实拍质感
空间方位：红袄女孩在画面左、面朝右的电话亭；霓虹招牌在右上；积水倒影铺前景
参考素材：<Picture 1>（image_id）：红袄女孩面部+全身身份锚点，不负责场景；<Picture 2>（image_id）：天台环境与光线，不负责人物
环境底噪：雨声密集贴耳 / 远处车流低闷｜音乐：N/A
```

**每个镜头一块（≤300 字，五行；无对白省略对白行）**：

```
[Shot 1] At 00:00.0–00:04.2 · 中景/平视 · dolly in 慢速小幅，落幅停在手部【揭示】
画面：红袄女孩——齐眉刘海红头绳短辫、大红织金小袄袖口磨毛（后续同人物写"同S1-1"）；右手从身侧抬起→指尖悬在按键上方一寸停住→按下；前景雨滴贴镜头滑落，远景霓虹在积水里拉成竖条，青色高光落右颊
对白：<d>[中文] 还是要走了吗。</d>（S1，气声，[2.0s] 起）
特效：镜头水渍——雨滴缓慢下滑拖出透明水痕
声音：[3.4s] 按键咔哒单次 / 雨打亭顶密集脆响

[Shot 2] At 00:04.2–00:10.0 · …（后续镜头同构）
```

- 镜头标题行：`[Shot N] At <起点>–<止点>`，本段局部时间、0.1s 精度、严格递增、无空隙——首镜从 00:00.0 起，末镜止于全段时长；模型按这条时间轴安排每秒画面
- 运镜四要素（类型+幅度+速度+落点）写在标题行，叙事手法以【】标注——**不单起一行写理由**
- 动作分解、空间朝向、环境三层、光线落点**融进"画面"一行**，具体名词直接给，不加小标题
- 对白行：`<d>[中文] 原话。</d>` +（S1）说话人编号与语气、起始时间；上游台词一字不改
- 每镜"声音"行只写该镜的动作音效；全段环境底噪与非叙事音乐落在头部第四行。**所有秒级卡点（音效 `[3.4s]`、对白 `[2.0s]` 起）都用本段局部时间**，与 [Shot N] At 同一坐标系——不写镜内相对时间
- 参考素材行：输入参考图按顺序映射 `<Picture 1..N>`（括号内写输入清单中的实际素材 ID），每张写清负责/不负责什么——堆多了产生平均脸和风格串台；**输入没有参考图时整行省略，禁止虚构 `<Picture N>` 标签**（模型会按标签调取不存在的素材）
- 人物外观只在首次出场写全，同段后续写"同S1-N"（**仅限本段内引用**）；**跨段承接时不写"同S1-N"**（上段定义不在本段提示词里）——人物身份已由上一段结尾画面延续，用一句外观锚点（称呼+服饰色彩+关键特征）带过，不重贴全套外观
- **禁止输出**：运镜论证（"删掉它剧情就不成立"式解释）、设计说明、自检清单、速查索引表、任何给创作者看而非给模型看的内容

**交付前自检（内审用，绝不输出到产物）：**

- [ ] 每镜运镜过"删掉它剧情断在哪"内审；镜头领先不尾随；标注了叙事手法
- [ ] 每镜能说出叙事任务，景别由任务决定；连续特写 ≤ 2；特写都答得出"放大什么"；无凑数特写，景别有呼吸（建立/推进/重音有分布）；非特写镜头的身份有外观锚点
- [ ] 伏笔铺垫低调、回收有呼应
- [ ] 每镜行齐全（标题/画面/对白*/特效/声音）；画面含动作分解、朝向、环境、光线
- [ ] 单段（8–15s）2–5 镜；真实切镜才开新 Shot（运镜/动作变化不构成切镜）；时间戳严格递增、无空隙、首镜 00:00.0、末镜覆盖全段
- [ ] 每镜头主特效 ≤ 2 且绑定光源/运动；微观特效均绑特写；重要特写有 ≥1 特效承载点
- [ ] 四层音效齐全（头部环境底噪/音乐行不空）；关键音效卡在动作和时间点；对白均为 `<d>[中文]</d>`+(S1)
- [ ] 空间方位行已写；视线与方位一致；朝向链不断；背对目标用了"反应特写+想象插入"
- [ ] 风作用于 ≥ 3 处方向一致；每场景 ≥ 1 生命层动态；动必有因
- [ ] 每镜过拍摄测试；单镜 ≤ 300 字，无注水
- [ ] 参考素材 `<Picture N>` 与输入清单顺序一致、职责单一；overlap>0 时复现区与上段末尾逐项一致、非末段结尾为稳定镜头
- [ ] 无新增改变剧情因果的内容；灰区已列「新增元素清单」（仅确有灰区时）
- [ ] 画面可见文字逐字写出

## Rules
**跨段衔接（Guide 机制）** - 相邻分镜用重叠区（overlap 秒）保持连续，模型以上一段结尾画面作为本段开头的视觉锚：

- **overlap > 0**（输入会给出上一分镜完整提示词与 overlap 秒数）：
  - 本段 `[Shot 1]` 覆盖 00:00.0 至 overlap 区间，**逐项复现上一段末尾状态**——人物站位、姿势、表情、朝向、动作相位、手中道具、机位景别、灯光、持续的环境声，与上一段提示词的末尾一致；不加新动作、新台词、新构图
  - 新剧情从复现区结束后开始：同一镜头延续则仍写在 [Shot 1]（"复现结束后不切镜，继续……"），真实切镜才开 [Shot 2]
  - **本段末尾（本集最后一段除外）同样保持一个稳定可延续的镜头**供下段复现：中低速动作相位、人物轮廓清晰、站位可分离、灯光稳定——不塞新剧情、快速动作或多人交叉
- **overlap = 0**：正常开场，提示词中不出现任何衔接语义
