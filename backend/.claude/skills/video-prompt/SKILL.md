# 视频提示词生成

用户给你三句话，你要还他一份**能直接开拍的拍摄任务书**。

这个 skill 处理的是一条流水线：**零散想法 → 场景序列 → 电影级脚本 → 分镜表**。四步全由本 skill 完成，**最终产物是分镜表**。

**本 skill 是独立、自包含的**——不调用任何其他 skill。分镜表之后如果需要转成特定模型的提示词格式，由用户自行使用相应的 skill 或工具，那不是本 skill 的职责。

产出质量的判据只有一条：**拿到这份东西的人，能不能不追问一句就开工。** 凡是需要他回头问"所以画面里到底有什么"的地方，都是没做完。

---

## 流水线：三步走

每一步的产出都是下一步的输入，**不要跳步**——直接从"三句话"跳到分镜会丢掉戏剧结构，产出的是漂亮但空洞的镜头拼盘。

> **贯穿全程的一条主线：运镜牵引剧情。** 从第 ① 步起，每一拍的定义就由"镜头做什么"给出，而不是"角色做什么"。镜头是叙事者，不是记录仪。详见铁律二。

| 步骤 | 做什么 | 读哪个文件 |
|---|---|---|
| ① 场景扩写 | 三句话 → 有起承转合的场景序列 | `references/scene-expansion.md` |
| ② 电影级脚本 | 每个场景 → 细节丰富、有画面感的文字脚本 | `references/cinematic-script.md` |
| ③ 分镜设计 | 脚本 → 带运镜/特效/音效的分镜表（最终产物） | `references/shot-and-sound.md` |

**第 ① 步做完必须停下确认**——场景结构定错了，后面两步全部返工。**① 确认后，②③ 连续完成、一并交付，不再分步停**——特写配额和节奏规则只在 ③ 可验证，拆开交付等于让用户验收不了核心指标。

## 七条铁律

这七条决定产出能不能用。参考文件讲"每一步怎么做"，这里讲"什么绝对不能犯"。

### 一、细节密度：每一帧都要能被摆出来

"具体画面感"不是"没有空词"，是**密度**。

一句描述能过删词测试，只说明它不是废话——**不代表它写够了**。绝大多数"细节太少"的返工，都是把及格线当成了终点线。

#### 两道测试

**删词测试（及格线）**：把形容词删掉，画面信息还在不在？

- ❌ "女主显得很孤独" → 删掉"孤独"，句子空了
- ✅ "她坐在没开灯的客厅地板上，电视待机红灯是画面里唯一的光源，在她侧脸投下一小块红斑"

**拍摄测试（目标线）**：把这段描述给一个**没见过你的人**，他能不能**原样把画面摆出来**？

- ❌ "她在热闹的市集里跑" → 摆不出来。"热闹"有哪些摊位？"跑"是小跑还是疾奔？地面什么材质？手里拿着什么？
- ✅ "她提着月白马面裙的裙摆，从卖绢花的席棚和卖糖人的担子之间侧身挤过，虎头棉鞋在青砖上敲出急促的碎响"

#### 七维清单

**每一个节拍（通常在 3 秒内的一个镜头）必须同时写到下面七项，缺一项就是没写完。**

> **外加第零项「运镜叙事」，排在最前——见铁律二。** 七维描述的是"画面里有什么"，运镜叙事描述的是"镜头怎么把画面交出来"。先有运镜，再有七维。

| 维度 | 写什么 | ❌ 太薄 | ✅ 够密度 |
|---|---|---|---|
| **人物外观** | 五官、发型、服饰的材质与颜色、随身物件 | "穿着古装的小女孩" | "齐眉刘海，两条短辫用红头绳扎着，鬓边别一朵绒花，大红织金小袄的袖口磨出一点毛边" |
| **动作分解** | 起始 → 过程 → 结束，写清哪个部位先动 | "她跑过去" | "左脚蹬地、裙摆鼓起、辫子甩到身后又荡回来、上身微微前倾、右脚跟上、连跑三步" |
| **环境三层** | 前景 / 中景 / 远景各有什么具体物件 | "热闹的市集" | "前景是虚化的糖人担子，中景是她，远景是席棚顶上一排招展的布幌和更远处的宫墙黄瓦" |
| **光线落点** | 来源方向 + 性质 + 在主体身上形成什么 | "光线很美" | "冬日斜阳从右后 30° 切入，在她左脸勾出一道暖色边缘光，其余落在冷调阴影里" |
| **材质与空气** | 表面质感 + 空气中的微粒 | "质感很好" | "织金小袄随动作泛出细密的金点，光柱里浮着缓慢游移的细尘" |
| **声音** | 这一拍里有哪些声音在响 | "有环境音" | "远处铜盆被撞响的脆声、摊位前的人声嗡鸣、她鞋底敲青砖的紧凑节奏" |
| **空间与朝向** | 人物位置、面朝方向、视线落点的方位（以画面左/右表述，与场景卡的空间方位表对齐） | "她看向冰糖葫芦" | "她在画面左三分之一、面朝画面右；糖葫芦摊在她右前方红墙根，她的视线锁定草靶，瞳孔高光在右侧" |

#### 量化下限

保底标准，不是目标：

- 单个节拍的画面描述 **≥ 80 字**
- 单个场景的文字脚本 **≥ 600 字**
- 每个节拍至少出现 **8 个具体实物名词**（形容词不算、抽象名词不算）

**达不到就是没写够。回去补，不要交付。**

#### 细节 ≠ 形容词堆砌

**细节是具体名词 + 精确动作 + 可测量的物理量。** 动作必须给明确词汇再分解——写"她跑过去"模型只能瞎猜，写"左脚蹬地、裙摆鼓起、辫子甩到身后又荡回来"才有物理。完整动作词汇库（踱步 / 疾走 / 小跑 / 冲刺 / 疾飞 / 旋身 / 攥紧 / 顿住……按速度档位选用）见 `references/shot-and-sound.md` 的「动作必须明确」节。

> "斑驳的、沧桑的、充满历史感的宫墙" → 零细节（三个形容词，零信息）
> "宫墙的红漆起了翘皮，露出底下灰白的灰浆，一道裂纹从墙根斜着爬到半腰" → 三个细节

**永远不要写观众看不见的东西**——内心活动、前史、人物关系，全部转成动作、道具、光线、构图。想表达"她很期待"，就写"她的脚尖不自觉地往前挪了半步，又收回来"。

### 二、运镜牵引剧情——镜头是叙事者，不是记录仪

"镜头动作牵引剧情发展"是一个硬要求：**运镜本身必须承担叙事功能，删掉它剧情就断。**

#### 判据：删掉运镜，剧情还成立吗？

- ❌ 删掉运镜、只剩主体动作，剧情照常推进 → 这个运镜只是"记录"，是装饰，**不合格**
- ✅ 删掉运镜，剧情就断了 → 这个运镜在讲故事，**合格**

> "她转头看向糖葫芦，镜头跟着摇过去" —— 运镜是尾随，删掉毫无影响。
> "镜头先摇向草靶，她的脸随后转过来" —— 运镜是**牵引**，删掉就没有"被诱惑"这件事了。

#### 五种牵引手法

| 手法 | 怎么做 | 制造什么 |
|---|---|---|
| **领动** | 镜头先于主体动起来 | **预期**——观众先于角色知道要发生什么 |
| **揭示** | 镜头移动把新信息带进画面 | **转折**——信息"进入画面"这个动作本身就是剧情转折 |
| **牵引** | 镜头把两个物体 / 人物连起来 | **因果**——"她想要那个"这个关系由镜头建立 |
| **压迫 / 释放** | 推近累积压力，甩开释放压力 | **情绪节奏** |
| **同步 / 反向** | 与主体同向＝陪伴加速；反向＝阻力 | **力量关系** |

写法与范例见 `references/shot-and-sound.md`。

#### 铁则：镜头要领先，不要尾随

默认写法是"她做了什么，镜头跟着拍什么"——**镜头永远慢半拍，永远在记录已经发生的事**。改成镜头先动、主体后动：

| ❌ 尾随（镜头是记录仪） | ✅ 领动（镜头是叙事者） |
|---|---|
| 她转头看向糖葫芦，镜头跟着摇过去 | 镜头先摇向草靶，她的脸随后转过来 |
| 她跑起来，镜头跟着她跑 | 镜头先朝草靶方向冲出去，她的身体随后冲进画面追上来 |
| 她抬头看父亲，镜头摇到父亲脸上 | 镜头先抬到父亲脸上，她的视线随后跟到 |

**每个节拍都问一句：这个镜头是我在"跟着拍"，还是我在"讲故事"？**

#### 镜头永远在动，3 秒是节奏基准

这是硬约束，交付前必须自检。**"在动"只是底线——动得有意义才是目标。**

**节拍 = 切镜点 ∪ 运镜变化点**。规则：

1. 相邻两个节拍的间隔**以 3 秒为基准**——争取落在 3 秒以内，但这是节奏参考，不是死线
2. 第一个节拍在 `0.0s`——开场就在动，没有"静起"
3. 节拍必须覆盖到片尾，不能有尾巴

换句话说，常态下任意 3 秒左右的窗口内，**要么切了镜，要么镜头运动状态变了**（起幅→落幅、加速、变向、变焦、跟焦转移）。真正不许的只有一件事：**镜头静止且无变化地拖下去**。

**时长跟着内容走，不跟秒表走。** 3 秒是主力区间，不是截断值——该长就长，该短就短：

| 可以超出 3 秒 | 不成立的借口 |
|---|---|
| 情绪重音需要呼吸（手停在门把上那两秒） | 懒得设计运镜变化，一刀长镜头糊弄 |
| 复杂运镜需要时间展开（螺旋拉近、环绕） | 信息量撑不满时长，画面空转 |
| 大空间建立交代（俯视大远景扫过） | 该切分的对话/动作被硬塞进一个镜头 |
| 关键动作的完整分解（起跑的全身联动） | |

**判断标准：把这段镜头静音、2 倍速快进，还在损失信息吗？** 每一秒都有新信息 → 时长合理；快进不损失任何东西 → 时长虚胖，切短或加节拍变化。

> 不要机械地每 3 秒切一次镜，那是 MV 式碎剪；也不要为凑 3 秒把该长的镜头掐断，那是秒表剪片子。**"永远在动"是底线，3 秒是基准，不是牢笼。**

**刻意静止仍是受控例外**：整片允许 1–2 处刻意静止作为重音（比如情绪落点），须在分镜表里注明「刻意的静态重音」。滥用这个例外等于没有例外。

运镜写法见 `references/shot-and-sound.md`，核心要求：**运动类型 + 幅度 + 速度 + 落点**，四要素齐。（写"环绕运镜"模型接不住，写 `truck left + pan right` 才接得住。）

**禁止沿用默认运镜。** 全片不许只会"推 / 拉 / 摇 / 跟"——俯视大远景、螺旋拉近、环绕、急速推镜、俯冲、窥视透过……每个都从 `references/shot-and-sound.md` 的扩展运镜库里**按叙事功能选**。运镜没有变化的片子，等于镜头没在讲故事。

### 三、特写与特效——影视感的第一素材

**优先级：仅次于运镜。** 特写 + 特效是"影视作品"和"监控录像"的分水岭。给足了是作品，给不足是记录。用户要的"真实感"，主要靠这一对撑起来——AI 视频廉价的根源，就是特写太少、特效太虚。

#### 特写配额：宁多勿少

- **特写 + 大特写 ≥ 总镜头数的 40%**
- **特写 + 大特写 + 中近景 ≥ 60%**
- **支点、情绪点、揭示点必须用特写或中近景承载**——不给全景
- 全景 / 远景只做一件事：建立空间、撑起起承转合的骨架

为什么：观众记住的全是特写——她的眼睛、糖壳的反光、攥紧又松开的手。**情感几乎全在特写里**，远景只负责交代"这是哪"。

#### 特写必须承担叙事功能，不是凑数量

每个特写都要回答"**它放大了什么**"：

- **放大情绪**：她眼里的光、微微张开的嘴唇
- **放大因果**：攥着糖的手松开（"想要去要"的信号）
- **放大质感**：糖壳的反光、睫毛上的霜

**随便给个脸部大特写 = 凑数。** 删掉它剧情和情绪都不受影响，那就是无效特写。

#### 特效与特写是天然搭档

**特效是微小的东西，远景里根本看不见，特写里才存在。**

- **微观材质类特效必须绑定特写镜头**——远景里写"她睫毛上有霜花"不可见，特写里才是特效
- **每个特写镜头至少要有 1 个特效承载点**（材质 / 空气 / 光学，任选）
- 远景 / 全景只用"大气"类特效铺氛围（雾、体积光、蒸汽），不承担质感任务

#### 特效的密度与纪律（不可因"给足"而失控）

"给足特写和特效"≠ 堆砌。**密度是镜头层面的，纪律是单镜层面的**：

1. 每个镜头主特效 **≤ 2**——超过会互相打架，画面变脏。给足 = 让**更多镜头**带上特效，而不是单镜堆更多
2. 特效必须**绑定光源或运动**才不假
3. 特效**写行为，不写名字**。"丁达尔效应"不可拍，"午后斜阳从百叶窗缝隙切入、照亮空气中的浮尘、形成可见光柱"才可拍
4. 全片保持**统一的 C 类光学特效签名**（贯穿全片，见下表）

#### 特效三类分工

| 类别 | 负责 | 常用场景 |
|---|---|---|
| **大气/物理** | 真实感 | 雾、蒸汽、体积光、浮尘——铺远景氛围 + 特写里的呼吸白气 |
| **微观/材质** | 细节感 | 糖壳反光、皮肤绒毛、织金纹理——**特写的领地** |
| **光学/摄影机** | 高级感 | 变形眩光、焦外光斑、胶片颗粒——全片统一签名 |

完整特效库与搭配原则见 `references/cinematic-script.md`。

### 四、音效是场景的一半，按层写

**分四层规划，分开写**：

1. **对白**——谁说的、什么语言、原话
2. **物理音效**——画面里什么东西发出了什么声音，**绑定到产生它的动作和时间点**
3. **环境声**——贯穿全片的空间底噪（这条最容易漏，也最能拉开质感差距）
4. **非叙事音乐**——观众能听见、角色听不见的配乐

关键声音要**卡在动作上**：`[6.2s] 拉环声，随后是短促的气泡声`。环境声要有空间信息（远近、混响、干湿）——"空旷仓库的混响"和"贴着耳朵的呼吸声"是两个完全不同的空间。

音乐写**乐器、节奏、结构**，不写情绪词。"紧张的弦乐"没用，"低频弦乐持续音 + 每 4 秒一次的定音鼓"才有用。

### 五、忠于输入 ≠ 不许展开

用户给的**剧情、人物、台词、事件不能改，也不能加**。但用户只给一句梗概时，把它展开成可拍的分镜——景别、机位、光线、环境声、外观细节——**正是这个 skill 的工作本身**，不是"发明内容"。

判断标准只有一条：**新增的东西是否改变了剧情因果。**

- 给"一只猫"补上"布偶猫、蓝眼睛、蓬松长毛" → **展开**，照做
- 给猫加一个"突然被窗外的鸟吸引"的新转折 → **发明**，要问

**两类灰区：不改变因果，也必须声明。** 以下新增内容交付时单列一份「新增元素清单」，给用户一句话否决的机会——不声明就放进成片 = 越界：

- **贯穿性道具**：会在多个镜头出现、或承载情绪/动作的物件（如"她手里攥着拨浪鼓，起跑时脱手落地"）。它会被反复拍到，用户无法忽略
- **人物新增反应**：用户没写的表情与动作反应（如"爹被拽得低头，嘴角动了一下"）

同理，用户没给时长、没给台词文本、没给人物名字时，**先按默认值处理并在交付时说明**，不要停下来等。只有缺"会改变整体结构"的信息（单段还是多段、总时长、投放平台）时才值得先问一句。

### 六、空间物理一致——视线、朝向、位置必须几何自洽

AI 视频最容易被识破的破绽不在"不够美"，在**违背物理规律**：人物看的方向和目标不在同一侧、上一镜头还面对的人下一镜头变成背对、动作衔接凭空跳变。分镜表不只是"拍什么"，还是一份**空间几何约束**。

#### 空间方位表（第①步必建，全片的几何基准）

场景卡里必须写清：**每个人物、关键道具各在哪个方位**（用"画面左/右 + 前后关系"表述），**每个人物面朝哪里**。之后每一个镜头的视线方向、转头方向、走动方向、镜头机位，都要与这张表对得上。方位表建错了或没建，后面每一镜都在赌模型自己猜。

#### 视线几何：视线方向必须指向目标的真实方位

- 她在画面左、目标在画面右 → 她的眼神和头必须朝画面**右**看，特写里瞳孔高光的位置也要与之自洽
- **主体背对目标时，禁止用同一个镜头表现"她看到了/眼睛发亮"**——观众看不到她眼睛的朝向，模型也只能瞎猜。此时必须切镜，标准解法是"反应特写 + 想象插入"两连：
  1. **反应特写**：切一个只对她脸的正/侧脸特写，明确写"视线朝画面右（目标方向），瞳孔点亮"
  2. **想象插入（insert）**：紧接一个她的主观镜头或想象画面（目标物的特写），"她想的就是这个"由镜头完成因果，不靠观众脑补
- 凡含"看 / 瞥 / 盯 / 望 / 回头"的镜头，详述块的「空间与朝向」维必须写明**视线落点的方位**

#### 朝向链：人物的朝向变化必须被镜头交代

每个人物跨镜头的**面朝方向**构成一条链，链条不许断：

- 上一镜他面朝 A → 下一镜他面朝 B → 中间必须有一个镜头（或本镜内的动作分解"转身 →"）展示从 A 到 B 的过程
- **禁止切镜后人物凭空换向**。爹上一秒还面朝女儿看着她跑，下一镜绝不能直接背对女儿站着——要么先拍他转身，要么重新设计机位让他保持面朝女儿
- 双人互动（拥抱、拽袖、递物）之前，先在方位表上核对两人的相对位置与朝向**是否允许这个动作发生**；不允许就先给一个调度镜头

### 七、环境活性——世界不是只为主角转的

环境单一、静止，是"影棚感"和"CG 感"的来源。真实世界有两个特征：**力是系统的，生命是自主的。**

#### 风是系统的，不是单点动画

风一旦存在，必须作用于**同一场景 ≥ 3 处**可见对象，且方向一致、同步呼应：

- ❌ 只有风车在转，布幌、发丝、衣袂都纹丝不动 → 孤立动画，一眼假
- ✅ 风车在转 + 红墙根布幌朝同一方向招展 + 她的鬓发和裙摆被吹起 + 干叶贴地滚过 + 呼吸白气被吹斜
- 场景卡的「环境动态」槽位写明：**风向（别和光源方向混写）、风力等级、受风对象清单（≥3 项）**，分镜时逐镜落实

#### 环境生命层：每个场景 ≥ 1 个与剧情无关的动态元素

天上过鸟、檐角旗子翻动、远处行人走过、树叶飘落、水面涟漪——这些**不参与剧情**的自主动态让世界"活着"。每个场景至少安排 1 个，写明它出现在哪个节拍。

- 生命层也要过拍摄测试："一只鸟飞过"不可拍；"两只寒鸦从画面右上斜掠过殿顶，翅膀连拍两下"可拍

#### 动必有因

画面里每一个运动的物体都要能回答"**谁/什么让它动**"：风、重力、人物触碰、动物、惯性。答不出动因的运动是模型自由发挥的重灾区——删掉它，或给它一个因。

## 输出契约

### 中间产物：分镜表

第 ③ 步的产出是**双层结构**：上面一张**索引表**，下面每个镜头一块**逐镜详述**。它是本 skill 的最终产物。

**表格只做索引，细节全在详述块里。** 只有表格没有详述块 = 没做完。

```
【场景 S1】雨夜天台 · 0.0–8.0s
  戏剧任务：她决定打这通电话
  光线：单一霓虹光源（青），无补光
  ─────────────────────────────────────────────
  #  时间        时长  景别/机位   运镜          特效          声音
  1  0.0–1.6s   1.6s  中景/平视   dolly in 慢   雨丝+镜头水渍  雨声/按键咔哒
  2  1.6–2.4s   0.8s  特写/俯拍   rack focus    浅景深光斑     呼吸声
  ...
```

**逐镜详述块**（每个镜头一块，七维齐全）：

```
┌ 镜头 1 · 0.0–1.6s · 中景/平视 · dolly in（中幅/慢/落幅停在手部）
│ 运镜叙事：【揭示】镜头先从她身后朝电话亭推近，把"无人接听"的红灯带进
│          画面；她抬手的动作是对这个揭示的回应——删掉这个推近，
│          "她意识到没人接"这件事就不存在了
│ 人物外观：齐眉刘海，两条短辫用红头绳扎着，鬓边别一朵绒花，大红织金
│          小袄的袖口磨出一点毛边，月白马面裙下露出虎头棉鞋的鞋尖
│ 动作分解：右手从身侧抬起 → 食指伸直、其余三指收拢 → 指尖悬在按键上
│          方一寸处停住 → 按下 → 手腕回收
│ 空间朝向：她在画面左、面朝画面右的电话亭；视线落点在电话亭的按键区，
│          与场景方位表一致（镜头 1 为起始朝向；此后每拍写明与上一拍
│          朝向如何衔接）
│ 环境三层：前景是虚化的雨滴贴着镜头玻璃滑落；中景是她和铁皮电话亭；
│          远景是被雨水泡糊的霓虹招牌，红绿两色在积水里拉成竖条
│ 光线落点：单一霓虹光源（青）从画面左上斜下，在她右脸颊扫出一道冷色
│          高光，左手完全落在暗部
│ 材质空气：雨滴附着在镜头前，焦点在雨滴与她之间游移；大衣肩头的呢料
│          吸了水颜色变深，表面立起一层细密绒毛
│ 特效（主）：镜头水渍——雨滴缓慢下滑，拖出一道透明水痕，短暂扭曲后方画面
│ 声音：雨声（密集、贴耳）/ 按键咔哒（单次、干脆）/ 远处车流（低、闷）
```

每个镜头都要写到这个密度。**人物外观可以复用（同一人物只需在首次出现时写全，之后写"同 S1-1"），其余各维每个镜头都要重写**——因为运镜、动作、朝向、环境、光线、材质、声音每时每刻都在变。

**"运镜叙事"这一行是详述块的灵魂。** 它同时回答三件事：镜头怎么动、这个动在讲什么、删掉它剧情断在哪。**写不出第三件事，说明这个运镜可以直接删掉**——删掉，然后重新设计一个真的在讲故事的运镜。

**交付前自检（必做，但不要把过程写给用户）：**

- [ ] 镜头时长以 3s 内为主；超出 3s 的镜头都有明确的内容理由，且内部有节拍变化、持续给新信息
- [ ] 首个节拍在 0.0s，末尾节拍覆盖片尾
- [ ] 每行都有运镜，且写明类型+幅度+速度+落点
- [ ] **每个节拍的运镜都承担叙事功能**——删掉它，剧情会断
- [ ] **镜头是领动的，不是尾随的**（镜头先动，主体后动）
- [ ] 每拍标注了牵引手法（领动 / 揭示 / 牵引 / 压迫释放 / 同步反向）
- [ ] 每镜头主特效数量 ≤ 2，且绑定光源或运动
- [ ] **特写+大特写 ≥ 40%**（特写+大特写+中近景 ≥ 60%）
- [ ] **支点 / 情绪点 / 揭示点用特写或中近景承载，未用全景**
- [ ] **每个特写都标注了"放大什么"**（情绪 / 因果 / 质感）
- [ ] **每个特写镜头 ≥1 个特效承载点**（材质 / 空气 / 光学）
- [ ] **微观材质类特效均绑定特写镜头**（远景里不出现质感特效）
- [ ] 四层音效齐全（尤其环境声不能空）
- [ ] **每个节拍七维齐全**（人物外观 / 动作分解 / 空间与朝向 / 环境三层 / 光线落点 / 材质与空气 / 声音）
- [ ] **空间方位表已建立**；每个"看/瞥/望/回头"镜头的视线方向与方位表一致
- [ ] **主体背对目标时用了"反应特写 + 想象插入"，没有在同一镜头里硬演"眼睛发亮"**
- [ ] **人物朝向链连续**——没有切镜后凭空换向；双人互动前两人的位置朝向允许该动作发生
- [ ] **风作用于 ≥3 处可见对象且方向一致**——没有孤立动画（如只有风车转）
- [ ] **每个场景 ≥1 个环境生命层动态元素**（鸟/落叶/远处行人等，不参与剧情）
- [ ] **每个运动的物体都有明确动因**（风/重力/触碰/动物/惯性）
- [ ] **每个节拍画面描述 ≥ 80 字，且含 ≥ 8 个具体实物名词**
- [ ] **每个场景文字脚本 ≥ 600 字**
- [ ] **每个镜头都有逐镜详述块**，不是只有表格里的一行
- [ ] 全过拍摄测试（拿给没见过的人，能原样摆出来）
- [ ] 没有新增改变剧情因果的内容
- [ ] 画面可见文字已逐字原文写出

### 最终产物：分镜表

分镜表就是本 skill 的最终产物，到 ③ 为止交付完成。

交付分镜表时，在表后附上三个信息，方便用户后续接入任何工具或模型：**总时长、是否分段、有没有参考素材（各几个、分别负责什么）**。素材的纪律仍然适用：**每个素材只负责一件明确的事**，并写清它**不**负责什么——素材堆多了不会提高一致性，反而产生平均脸、产品变形和风格串台。

另外提醒用户一句：如果后续把分镜表转成模型提示词，**运镜必须仍然在牵引剧情**，不能被压扁成"镜头跟着她跑"这种记录式描述——这条约束跟着分镜表走，无论用什么工具转换都要保住。

## 常见失败

| 症状 | 优先怀疑 |
|---|---|
| **用户说"细节太少"** | **违反铁律一：过了删词测试就交付，没做七维清单和量化下限。这是最高频的返工原因** |
| 用户说"还是不够具体" | 七维里某一维缺失——最常见是**环境三层**和**材质与空气**只写了主体 |
| **提示词像监控录像** | **违反铁律二：运镜只是尾随主体，删掉它剧情照样走。这是"镜头没有牵引力"的典型症状——最高频的返工原因之一** |
| 镜头很花哨但故事没推进 | 违反铁律二：运镜在"动"，但没承担叙事功能，属于装饰性运镜 |
| **画面像监控、没有影视感** | **违反铁律三：特写+中近景不足 60%，微观材质类特效绑在远景上（远景里根本看不见）。特写和特效给足了才是作品** |
| 特效很用力但看不到效果 | 违反铁律三：微观材质类特效给了远景/全景，改成特写承载 |
| 特写很多但片子还是平 | 特写是凑数的——没标注"放大什么"，删掉它剧情情绪都不受影响 |
| 画面"很燃但很空" | 违反了铁律一：形容词堆砌，没有可拍的像素安排 |
| 节奏拖沓、观众划走 | 违反了铁律二：镜头静止无变化地拖长，或时长虚胖、内容撑不起时长 |
| 一眼假、像游戏 CG | 违反了铁律三：特效脱离光源和物理，堆砌粒子 |
| 画面"干"、不沉浸 | 违反了铁律四：缺环境声层，或音乐写了情绪词没写乐器 |
| 用户说"这不是我要的" | 违反了铁律五：为了好看发明了剧情转折 |
| **人物视线方向和目标对不上 / 背对目标却"眼睛发亮"** | **违反铁律六：没建空间方位表，或背对目标时不切"反应特写 + 想象插入"，指望模型自己猜朝向** |
| **人物切镜后凭空转身 / 换向** | **违反铁律六：朝向链断裂——转身过程没有被任何镜头交代** |
| **环境死板、只有一个物件在动** | **违反铁律七：风成了单点动画（没作用于 ≥3 处），且缺环境生命层（鸟/落叶/行人）** |
| 分镜表拿去接模型时无从下手 | 分镜表后没附总时长/分段/素材信息，用户无法判断怎么用 |

## 默认值

参考文件没覆盖、用户也没说的情况，按这里处理并在交付时一句话说明：

| 情况 | 默认处理 |
|---|---|
| 用户没给时长 | 单场景 8 秒；多场景按戏剧需要分配，总数说明清楚 |
| 用户没给画幅 | 按横屏 16:9 处理 |
| 用户没给风格 | 从内容本身推断（产品片→干净商业光；剧情片→自然光/低照度），并在交付时说明这是推断 |
| 用户没给人物名字 | 用功能性指代（"她""中年男人""女孩"），不擅自起名 |
| 用户没给台词 | 不虚构台词，用动作和环境声承载；若剧情必须有对白，问一句 |
| 用户口头说"图1/参考视频1" | 按用户给的顺序映射编号，回复开头用一行确认映射关系 |

拿不准的只有一种情况值得先问：**缺的信息会改变整体结构**（单段还是多段、时长量级、投放平台是竖屏短视频还是横屏广告）。其余一律先做，做完说明假设。

**一次只让用户改一个变量**——这样他才能判断是哪项修改起了作用，而不是面对一版全新的东西无从比较。
